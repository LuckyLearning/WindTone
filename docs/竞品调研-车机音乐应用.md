# 竞品调研 · 车机音乐应用

> 调研于 2026-10-18（在线资料：官方说明、更新公告、车主实拍反馈；车上应用市场需真机核实）。
> 对标对象：**汽水音乐车机版**（`com.luna.music.car`）与 **QQ音乐车机版** —— 在 DiLink 上适配得最好、被车主提及最多的两个参考竞品。
> 结论先行：**听风与竞品的差距不在版式，而在「默认音乐」语音注册与语音点歌能力。**

## 一、两款竞品的交互逻辑

### 汽水音乐车机版（30~40MB，字节）

- **布局**：横屏「**左封面 + 播放控制 / 右滚动歌词**」，上下滑动切歌；大按钮 + 高对比度；左上角一键切换场景模式（驾车 / 通勤 / 助眠 / 夜间放松等 10+ 智能播放模式）。
- **语音**：V1.1.27 起**深度适配小迪** ——「播放抖音热歌」「播放周杰伦」「下一首」「音量调大」「收藏这首歌」全链路执行。前提：车机设置里把它设为**默认音乐播放器**。
- **其他**：方向盘按键（播放 / 暂停 / 上一首 / 下一首 / 音量）；左导航右歌词的**分屏**；抖音扫码登录、手机歌单同步；车载音效引擎；无广告。

### QQ音乐车机版

- **布局**：单栏首页**六大版块** —— 「当前播放」最大卡片（点进播放详情页：歌词 + 进度 + 收藏 / 暂停 / 删除 / 切歌）+ 最近播放 + 本地音乐 + 为你推荐 + 个性电台 + 我的音乐；左上角设置（扫码登录）、右上角搜索（文字 + 语音输入）。
- **语音**：与小迪同类集成（歌曲搜索、播放控制、切换歌单）；方向盘 + 中控旋钮盲操；**导航时仍显示桌面歌词**。
- **其他**：日夜模式；手机资产同步。

## 三、小迪语音的接管机制（关键）

「你好小迪播放音乐」的完整链路：

1. 用户唤醒小迪并下达音乐指令；
2. 车机读**车辆设置 → 智能提醒 → 智能语音 → 「默认音乐」**里选定的应用；
3. 该应用此前**注册过语音服务**（声明「支持歌曲搜索与播放控制」）；
4. 语音指令送达应用执行：起播 / 切歌 / 音量 / 收藏 / 点歌。

要点：

- **「默认音乐」选择器只列注册过语音服务的应用**。未注册的第三方（含听风）连列表都进不去 —— 这是听风「语音完全叫不动」的根因。
- 方向盘按键走的是 MediaSession 标准通道，**与语音注册是两套机制**，所以听风「方向盘能用、语音不能用」。
- 新 OTA 动向（汉L/唐L）：**三分屏已放开第三方**（可选列表含汽水音乐、地图、抖音等）；**仪表歌词目前只对系统音乐（酷我 / 酷狗 / 网易云 / QQ音乐）开放**，第三方暂无通道。

### 调研结论：三条通道，只有一条适合听风（2026-10-18 深挖）

**① 官方合作通道（现状：进不去）**
比亚迪 2026-09 发布的「迪迪虾」智能体把语音生态升级为**开放平台（A2A / MCP 标准协议）**，但**音乐智能体的首发合作方是 QQ音乐 / 酷我 / 酷狗 / 网易云四家**；汽水音乐的小迪适配同样是字节与比亚迪的合作版本。这是**商务合作制**，独立开发者短期无法进入。

**② 社区 hack 通道（现状：不适合产品化）**
第三方「比亚迪音乐助手」（远方的小熊猫）用两条 ADB 指令让任意应用"被小迪叫到"：

```
adb shell cmd notification allow_listener <包名>/<NotificationListenerService>
adb shell pm grant <包名> android.permission.READ_LOGS
```

原理是**伪装成通知监听器 + 读取系统日志**，从小迪的识别结果里截获音乐指令再代为执行。代价：要用户执行 ADB、要 READ_LOGS（signature 级权限）、**0920 及更新系统已注册不到默认音乐列表**、切歌可能被系统媒体中心抢占。**不作为听风的功能路线**，仅作为机制佐证记录在此。

**③ 自研平替通道（结论：这才是听风该做的）**
「说歌名点歌」不必依赖小迪 —— 竞品的搜索框本身就支持**输入法语音听写**（QQ音乐车机版右上角搜索即文字+语音双输入）。听风车机版加一个麦克风入口 → 系统听写转文字 → 直接搜本地曲库起播，**零合作门槛、零 hack、当天就能上线**。这是当前唯一现实的「语音点歌」。

## 四、优先级修正（2026-10-18 调研后）

原判「默认音乐注册 = P0」**降级**：官方合作制进不去、hack 路线不产品化 → 转为**观望项**（关注比亚迪生态开放平台后续是否对个人开发者开放音乐技能注册）。新的 P0 替换为：

| 优先级 | 事项 | 理由 |
|---|---|---|
| **P0** | 车机版搜索框支持**输入法语音听写**（麦克风入口 → 文字 → 搜曲库起播） | 零门槛的「语音点歌」平替，竞品同款交互 |
| **P1** | 分屏 / 三分屏适配（`resizeableActivity` + 分屏布局） | 已进 BYD 三分屏白名单的应用（含汽水）才 usable；用户车上大概率用得上 |
| P2 | 歌词区上下滑切歌 | 低成本，竞品标配 |
| P2 | 场景化模式（驾车 / 通勤 / 助眠…一键切均衡器+睡眠+播放列表组合） | 竞品卖点，听风已有零件可组合 |
| 观望 | 默认音乐注册 / 语音点歌直控 | 等 BYD 开放平台对个人开放，或走商务合作 |
| 观望 | 仪表歌词 | BYD 未开放第三方通道 |
