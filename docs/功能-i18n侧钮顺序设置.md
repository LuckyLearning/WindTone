# i18n 侧钮顺序设置（第 7 批）

把 `SettingsOverlayPage.kt` 里**侧钮显隐 + 上下顺序**面向用户的硬编码中文抽进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–6 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 7 批。

## 覆盖范围

- 整体「显示悬浮窗侧钮」开关标题 / 开/关副标题（`oh_show_handles*`）
- 三颗单钮显隐开关标题与副标题（`oh_show_collapse*` / `oh_show_play_pause*` / `oh_show_player*`）
- 「侧钮上下顺序」标题与说明（`oh_order_title` / `oh_order_hint`）
- 顺序列表项名与序号行（`oh_name_*` / `oh_order_item`）
- 「恢复默认顺序」（`oh_restore_order`）
- 上移 / 下移 contentDescription 继续复用既有 `move_up` / `move_down`

## 刻意未改

- SoftEq / EqSheet（SceneChips 见第 8 批）
- `OverlayCollapseHelper` 引擎与 Prefs 写盘路径
- 悬浮歌词其余外观/高级参数文案（本页其它段落多数已 i18n）
- `versionName` / tag / release
- AccessibilityWatchdog 生产/测试文件

## 验证

- `./gradlew :app:testDebugUnitTest --offline --tests com.luckylearning.windtone.overlay.OverlayCollapseHelperTest`
- 人工扫：侧钮相关块无残留用户可见中文硬编码（注释除外）
