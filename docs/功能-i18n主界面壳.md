# i18n 主界面壳（第 14 批）

把 **MainScreen / MainScreenParts** 高流量壳文案（多选栏、存队列为歌单、快捷方式空库提示、外部分享搜索未命中、删文件 / 移文件夹确认）收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–13 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 14 批。

## 覆盖范围

- 多选栏：退出 / 已选计数 / 请选择 / 全选 / 反选 / 加入队列 / 移出曲库 / 删除文件（`ms_*`）；加入歌单复用 `ss_add_to_playlist`；收藏复用 `cd_favorite`
- 存队列为歌单：标题 / 正文 / 名称占位 / 默认名（`ms_save_queue_*` / `ms_playlist_name_hint` / `ms_default_playlist_name`）；保存 / 取消复用 `save` / `cancel`
- 快捷方式空库 Snackbar、外部搜索未命中 Snackbar（`ms_shortcut_empty_library` / `ms_search_not_found`）
- 删除单曲 / 批量删除文件 / 移除文件夹扫描结果确认框（`ms_delete_song_*` / `ms_bulk_delete_*` / `ms_remove_folder_*` / `ms_remove`）；删除确认钮复用 `delete`

## 刻意未改

- 空库整页 CTA（`LibraryEmptyHint` / `lib_lists_*` / `lib_setup_*`）此前已入库
- **CarLibraryScreen**（已第 15 批）/ ListeningReport / LibraryStats / SheetsScanScope（留给更后批次）
- Aliyun 整包 / SoftEq / SoftEqSpike / 播放内核
- versionName / tag / release

## 验证

- `./gradlew :app:compileDebugKotlin --offline`
- 人工扫：`MainScreen.kt` / `MainScreenParts.kt` 用户可见文案无残留中文硬编码（KDoc/注释除外）
