# 功能 · 文案一致性（A4）

> 已随 **v1.2.37** 出包（原文档占位曾写 v1.2.38）。

## 目标

用户可见的失败 / 权限 / 云盘断流提示统一成：**短原因 + 一条可操作路径**（句号衔接，含「下一步：」）。

## 真源

- `UserFacingCopy.withNext(reason, nextStep)`：拼装；原因里已含「下一步」则不重复。
- `UserFacingCopy.ensureNext(text, nextStep)`：外层包装（如「已跳到下一首」）时保留已有路径。
- `PlaybackErrorMessages.withNext` 委托到 `UserFacingCopy`（播放 IO / HTTP / 并行缓存等）。

## 本晚第二遍覆盖的高流量入口

| 入口 | 文件 | 下一步指向 |
| --- | --- | --- |
| 播放失败描述 | `PlaybackErrorMessages` | 网络 / 清理缓存 / 重新授权 / 诊断包 |
| 连续失败暂停 | `ErrorSkipPolicy.stopMessage` | 网络或文件；云盘重新授权；诊断包 |
| 失败跳下一首 | `PlaybackEngine` | 连续失败会暂停；云盘重新授权 |
| 悬浮歌词启动失败 | `PlaybackEngine` | 开启「显示在其他应用上层」或关再开 |
| 扫描失败 / 空目录 | `LibraryCore` | 权限 / 扫描范围 / 换有歌文件夹 |
| 删除被拒 | `LibraryCore` | 系统文件管理或写权限 |
| 无读取权限 | `FolderController` | 选目录授权或系统音频权限 |
| M3U 导出/读取/无匹配 | `M3uStore` | 可写位置 / UTF-8 清单 / 先扫描曲库 |
| 在线歌单拉失败 | `OnlinePlaylistRules.friendly` | 网络 / 地址 / 证书与系统时间 |
| 云盘账号/扫描/直链 | `values(-zh)/strings.xml` 若干 `aliyun_error_*` | 重试 / 重新扫码授权 / 确认文件 |
