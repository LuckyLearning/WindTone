# 版本历史

版本号遵循语义化版本；`versionCode` 每发一版 +1，打上 `vX.Y.Z` 的 tag 后由 GitHub Actions 自动构建签名 APK 并创建 Release。

> ⚠️ 标注了「重建数据库」的版本会清空歌单 / 收藏 / 播放统计 / 歌词偏移（详见[权限与更新](权限与更新.html)）。

| 版本 | 主要内容 |
|---|---|
| **1.1.11** | **均衡器与音效页扩展 + 重排**。<br>• 内置预设 **9 → 16 个**：按听感的 8 个（新增**温暖 / 明亮 / 通透**）、按流派的 8 个（新增**电子 / 民谣 / 嘻哈 / 舞曲**）。其中「温暖 / 明亮 / 通透 / 电子」在 1.1.5 的发版公告里就写过，但当时只写了文案没写代码——**公告里有的预设界面上根本找不到**，本版补齐并加测试钉住。老预设的 id 与曲线一个没动，已选的不会丢。<br>• 新增第四种音效 **混响**：关闭 / 小房间 / 中房间 / 大房间 / 中厅 / 大厅 / 板式。档位由系统效果器给死、没有连续量，所以做成一排片而不是滑块；本机不支持混响时只在混响那一块降级提示，**不会把整页判成不可用**。<br>• 页面按**使用顺序**重排为三段：**预设 → 频段 → 增强音效**。预设从横向滚动改为**自动换行网**（一组 8 个片时最后两个原先永远在屏幕外），选中项下方给一张说明卡；频段新增**曲线预览**（折线 + 零点虚线，拖滑块实时变形）；低音 / 环绕 / 响度 / 混响四项补上当前值。整页可滚动（上限 560dp）。<br>• 本版**不重建数据库**（schema 仍为 v5）；单测 206 项。 |
| **1.1.10** | **入口收敛：同一个目的地不再挂多处入口**。<br>• **「设置」只剩左侧抽屉一个入口** —— 顶栏「⋮」菜单里那一项已删（此前抽屉与菜单各挂一份）。<br>• **「检查更新」只剩「设置 → 更新」里那一处** —— 此前抽屉、顶栏「⋮」菜单、设置子页**三处**都有入口，现删掉前两处。<br>• 顶栏「⋮」菜单从此**只放就地动作**（扫描范围 / 重新扫描 / 导入音乐目录 / 重新匹配 `.lrc` / 深度扫描 / 收听报告），不再放跳转项。<br>• 车机版的左侧导航保留「设置」：那是车机里唯一的入口，且它本身就是左面板。<br>• 自动检查发现新版本时的提示文案由「设置 → 检查更新」改为「设置 → 更新」——设置主页上是「更新」分类卡，「检查更新」是它下面那一行，原来那句指到了并不存在的那一级。<br>• 本版**不重建数据库**（schema 仍为 v5）；单测 194 项。 |
| **1.1.9** | **车机媒体面板可浏览歌单**。<br>• 播放服务由 `MediaSessionService` 改为 `MediaLibraryService`（前者是后者的父类，播放 / 通知 / 前台服务能力一个不少），并实现浏览树：车机媒体面板的根目录下是「我的收藏 / 最近播放 / 最常播放」＋自建歌单，可逐级点进并**整单播放**（从第一首起按歌单顺序播放）。<br>• 此前车机只能做播放控制、看不到歌单层级，这条一直挂在[权限与更新](权限与更新.html)的「已知限制」里；本版补齐。歌曲节点的 `mediaId` 就是音频 URI，与播放页 / 队列 / 封面缓存同一套 id。<br>• 车机侧只做歌单这一层下钻，**不做专辑 / 歌手 / 文件夹**，也**不做车机侧搜索**（语音搜索入口刻意不声明，避免落到空实现上）。<br>• 本版**不重建数据库**（schema 仍为 v5）。<br>• 覆盖面到此收口：折叠屏铰链避让、Compose 文案抽资源、动态快捷方式、性能回归复核四项已**明确不做**（见《功能规划-第五期》§四）。<br>• 真机验证见[真机验证清单](真机验证清单.html) P1-6 / P1-7。 |
| **1.1.8** | **移除逐字歌词（卡拉OK）**。<br>• 逐字染色所需的一整套东西**整体删除**：字级时间轴数据（`LyricLine.words` / 行时长）、从普通 LRC 派生字级时间的算法、两套字级渲染（歌词页卡拉OK 组件与悬浮窗「已唱字数」）、「逐字歌词」开关、两个「已唱颜色」设置项，以及播放页的「逐字」徽标。<br>• **`.krc` / `.yrc` / 增强型 LRC 仍照常读取**，只是行内的字级标签（`<a,b,c>` / `(a,b,c)`）在解析时被剥离、时间轴只取行首，统一按**逐行**同步显示 —— 内容不丢，只是没有逐字点亮。<br>• 沉淀出一条新的不变量：**全应用只有「逐行」一种歌词精度**。于是歌词页与悬浮窗的当前行强调**只靠颜色 / 字号 / 字重 / 底色**，两个渲染器都不再需要播放位置，悬浮窗「内容不变就不重组」的判据也因此变简单。<br>• 本版**不重建数据库**（schema 仍为 v5）；老用户机器上已保存的逐字相关设置会留在配置文件里成为**不再读写的无效键**，不影响使用。<br>• 净减约 900 行（源码 + 文档 + 测试），单测 181 项。 |
| **1.1.7** | **修一处「说了谎」的歌词徽标**。<br>• 曲库列表的歌词来源徽标此前写作「有独立 `.lrc` 就显示 `LRC`，否则显示内嵌」——但应用**并不检测内嵌歌词**，于是**连一首歌词都没有的歌也被标成「内嵌」**。改为：没有独立歌词文件就**不显示徽标**，不虚报来源。<br>• 新增[真机验证清单](真机验证清单.html)：模拟器回答不了、必须真机确认的项目（悬浮窗 ROM 兼容、后台存活与省电策略、均衡器听感、真实格式兼容、车机与折叠屏、性能回归）。<br>• 工程侧随源码新增 AVD 生命周期脚本与测试曲库生成器（开发工具，不影响安装包）。 |
| **1.1.6** | **文档站上线 + 三项收尾**。<br>• 补齐一期欠账：**变调 ±12 半音**（一个八度，默认原调）与**睡眠定时「播完当前专辑」**（当前曲剩余 + 队列里后续同专辑曲目）。<br>• **逐字歌词对普通 LRC 生效**：在歌词加载层为只有行时间轴的歌词派生逐字时间轴，此前「开着逐字开关却没效果」的根因是数据不存在而非渲染问题。<br>• 拆分 `SettingsScreen.kt`（2165 行 → 7 个文件），工程结构回到「单文件 ≤ 600 行」。<br>• 项目文档迁移到本站在线发布。 |
| **1.1.5** | **均衡器预设重做 + 悬浮歌词三修**。<br>• 均衡器内置**两套并行预设**：「按听感」（原声 / 温暖 / 明亮 / 人声 / 低音 / 通透…）与「按流派」（流行 / 摇滚 / 古典 / 爵士 / 电子…），每个预设带一句短描述，弹层预设选择界面重设计。<br>• 悬浮歌词：**位置完全由拖动决定**（横纵自由拖，「居中 / 居左」只管窗内文字排版）；**宽度改为占屏宽百分比，默认 80%**（此前默认 100%，横向可移动量归零，表现为「只能上下拖」）。<br>• 修**增强 LRC 逐字染色失效**：行时长未计算 → 归一化分母为 0 → 整行要么全灰要么瞬间全亮。<br>• 发版脚本根治 tag 推送静默失败（六连败根因：`EXIT` trap 里的删除失败污染了脚本退出码，push 成功却返回非零）。 |
| **1.1.4** | **七项交互打磨**。<br>• **每个可调项都能「恢复默认」**：只在偏离默认时行尾出现 `↺`，写回值一律取自 `SettingsDefaults`。<br>• 侧边抽屉支持**在内容区右滑拉出**；抽屉「检查更新」补图标。<br>• **排序下沉到各视图**，各视图只列自己适用的排序项，按视图各记各的。<br>• 悬浮歌词**宽度按屏幕百分比可调**。<br>• **三处歌词颜色可配**（播放页已唱色 / 悬浮窗文字色 / 悬浮窗已唱色）。 |
| **1.1.3** | **UI 二次重构 + 第五期主体功能**。<br>• 底部五视图导航栏 → **顶栏汉堡 + 侧边抽屉**；设置页由「一主三子」改为**「一主六子」**（外观 / 播放 / 歌词 / 音乐库 / 更新 / 关于与诊断）。<br>• 曲库域按七摊拆分（`LibrarySession` + 7 个公开 Actions 接口 + 6 个控制器），`LibraryViewModel` 退为委托壳。<br>• 第五期批次 8/9/10 主体：**批量多选**、歌单**拖动排序 / 一键去重 / 队列存歌单**、**收听报告**、**重复歌曲清理**、启动器**快捷方式**、**平板 / 折叠屏双栏**。<br>• 修设置页二级页面返回后滚动位置丢失；lint Error 级清零。 |
| **1.1.2** | **悬浮歌词全面完善 + 移除通知栏歌词**。<br>• 新增 **1 行 / 3 行**排版、**居左 / 居中**对齐、**一键自检**（授权跳转三级降级，失败给结论）。<br>• 修三个「看不见」的根因：文字 View 被永久设为 `INVISIBLE` 从未绘制、位置算错、亮色底不可读。<br>• **移除通知栏 / 锁屏歌词** —— Media3 的通知正文只读 `artist` 字段，写进 `subtitle` 的歌词永远看不见；歌词落点收敛为桌面悬浮窗。<br>• 修切页 / 进详情返回后列表滚动位置丢失。 |
| **1.1.1** | 修复通知栏歌词完全不显示；桌面悬浮歌词的失败状态改为**可见提示**而不是静默。 |
| **1.1.0** | **架构重构版**（⚠️ 本版重建数据库）。<br>• **分域拆分 ViewModel**（曲库 / 播放 / 更新 / 设置），并移除全部兼容层与迁移脚手架。<br>• 引入 **Gradle Version Catalog**（`libs.versions.toml`）统一管控依赖与插件版本。<br>• 扫描目录落库登记（`scanned_folders` 表）；文件夹视图移除分组时同步移除对应导入目录。<br>• **移除 WebDAV 云盘功能**（方案否定：需自研对接网盘，且隔离目录与流式播放资质两道硬门槛无解）。<br>• 设置页拆成主页面 + 三个子页，入口行加摘要与右箭头。 |
| **1.0.6** | **构建与发布机制**。<br>• 产物按 ABI 分包（arm64-v8a / armeabi-v7a / x86_64 / universal）；Release 说明改为固定模板 + 发版时只替换版本号。<br>• 检查更新改回只走 GitHub 官方地址；下载线路支持自动 / 手动选择。<br>• 音频信息入口移入播放设置抽屉；路径显示为人类可读形式。<br>• 车载：播放页红心紧跟歌名；两栏主页底部播放条新增收藏键。<br>• 修：移除目录不再触发全盘扫描；文件夹组标题只显示末级目录名；目录顺序稳定存储。 |
| **1.0.5** | 修主题取色 / 自动更新开关不生效；悬浮歌词定位与拖动修正；文件夹视图按所选目录分组；新增**短音频过滤**（默认 60 秒，可改）。 |
| **1.0.4** | **桌面悬浮歌词**（前台服务 + WindowManager，锁定穿透 / 拖动调整 / 位置记忆 / 仅后台显示）；**车载模式开机自启**；**WebDAV 云盘音乐源**（后于 1.1.0 移除）；下载与检查更新**多线路自动降级**，解决国内直连 GitHub 慢的问题。 |
| **1.0.3** | **车载模式**：启动直进播放页 + 歌词页 **5 秒沉浸态**（自动收起顶栏与控件）+ 车机三栏横屏布局。 |
| **1.0.2** | 逐字歌词新增设置页开关（默认开启）；播放页控制区改**三段式布局**让播放键绝对居中、来源标签移到底部状态栏；更新检查主通道改为 `releases.atom`（不计 API 配额），API 降级兜底；tag 推送改走 `scripts/push.sh`，避免裸 `git push` 被 Windows 环境拦截。 |
| **1.0.1** | **播放控制与音乐库整理**。<br>• 播放模式合并：随机播放与循环模式原先各占一个按钮，现合并为播放页上的**单个按钮四态轮换**（顺序播放 → 列表循环 → 单曲循环 → 随机播放），切换时浮出模式名提示；控制区由 5 个按钮减为 4 个。<br>• 文件夹视图：不再显示无路径歌曲聚成的「未知目录」；SAF 来源的歌曲补齐真实目录（按目录树相对路径 + URI 反推），新增**「移除扫描结果」**可一次性清掉某个文件夹下的全部歌曲（不删除手机里的音频文件）。<br>• 新增 `PlayMode` 轮换与推导的单元测试，单测总数 28 → 32。 |
| **1.0.0** | **首个公开版本**。汇聚开发期多轮迭代的成果：三来源扫描（系统媒体库 / 指定目录 / SAF）、LRC 与内嵌歌词（含 KRC/YRC 逐字时间轴、双语合并、拼音搜索）、Media3 后台播放与通知栏控制、Room 歌单与播放统计、均衡器与响度增强、睡眠定时、桌面小部件与快捷磁贴、崩溃日志；R8 混淆后约 2.9 MB；界面为 M3 动态配色 + 封面主色渐变。<br>本版同时落地工程化能力：GitHub Actions（打 tag 自动出**已签名**包并创建 Release，主干/PR 跑 28 个单元测试）、应用内版本检测与一键升级。 |
