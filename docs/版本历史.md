# 版本历史

版本号遵循语义化版本；`versionCode` 每发一版 +1，打上 `vX.Y.Z` 的 tag 后由 GitHub Actions 自动构建签名 APK 并创建 Release。

> ⚠️ 标注了「重建数据库」的版本会清空歌单 / 收藏 / 播放统计 / 歌词偏移（详见[权限与更新](权限与更新.html)）。

| 版本 | 主要内容 |
|---|---|
| **1.1.27** | **开机后台播放抗住「开机那几个竞速」+ 在设置里能看到它走到哪一步**（用户再次提出「开机自启后后台自启播放，不打开主页面」）。<br>• **三次重试**：开机这一路要同时跟三件事赛跑 —— `MediaController` 还没连上（服务刚起，绑定是异步的）、曲库还没从数据库读出来、音频设备还没就绪导致 `play()` 被 HAL 吞掉。原来是「一次不成就放弃」，任一环节没赢就是「开关打开了、开机没反应」。现在按 0s / 4s / 10s 各试一次，并把失败原因按人话返回（「播放服务还没连上」「曲库是空的」「播放器没接受这首歌（存储可能还没挂载完）」等），而不是抛异常。总时长仍控制在 20 秒内，不会出现「开机十几秒后突然出声」。<br>• **起播确认从 800ms 放宽到 1.2s**：车机音频链路起振慢，800ms 常常还在缓冲，早先那次「补一次 play()」因此形同虚设；现在等够再判 `STATE_IDLE` / `playWhenReady`。<br>• **设置 → 关于与诊断新增「开机自启」卡片**：开关状态、上次开机广播距今多久、决策是什么、结果如何，一眼可见。这条链路只有真车能验（`BOOT_COMPLETED` 是保护广播，adb 发不出去），而所有失败表现都长成「开机后什么都没发生」——卡片把它拆成四种可区分的成因：广播没到（去开系统自启动权限）/ 决策是什么都没做（开关没开）/ 起播失败（原因照抄）/ 起了个头没下文（进程被回收，超过 60 秒未出结果按此解释）。<br>• **新增「立刻试一次后台起播」**：不重启也能把整条起播链路跑一遍（恢复队列 → 起播 → 落状态），验的时候不用反复开关机。<br>• **没有播放记录的机器也照样出声**：新装机（从没播过任何歌）时既没有队列也没有「上次那一首」，原先直接判「未起播」。现在退化为「从曲库第一首开始」——否则新用户第一次开机永远等不到声音，而他又不知道该先手动播一次。诊断卡会注明「从曲库第一首开始（之前没有播放记录）」。<br>• 记录单独存 `boot_status`，清空用户数据不会连带抹掉这条排障证据。<br>• 补测 8 条（诊断文案：从未收到 / 重试成功 / 失败带原因 / 原因缺失兜底 / 正在恢复 / 中断判定 / 决策文案 / 时间分档），单测 316 → **324 项**；lint 0 Error。<br>• 本版**不重建数据库**（schema 仍为 v5）。 |
| **1.1.26** | **「无底板」时的歌词可读性 + 开机播放的 ANR 修复**（2026-10-18 用户车机实拍：「无底板是，歌词模糊」）。<br>• 真机照片里浅色歌词压在泊车影像 / 浅色地图上，整块糊成一片。查下来不是渲染 bug，而是两个设置叠加：投影是「半径 3dp + 下移 1dp」的柔光，浅色字边缘被晕开；上下句只有 42% 不透明度，浅底上等于消失。<br>• **无底板时换成硬描边**：`setShadowLayer` 改为零位移 + 2dp 半径 + 不透明黑，边界立刻变硬；有底板时保持原柔光（底板已给对比度，再加深会显脏）。<br>• **无底板时提高上下文亮度**：上下句 0x6B → 0x9B（≈61%），译文 0xA0 → 0xBD（≈74%）；当前行仍是最亮的一档，层级不塌。参数抽到 `OverlayLegibility` 并补 3 条单测，防止以后又调回 42%。<br>• 设置页「悬浮歌词底板」在「无」档的副标题同步说清这套自动补偿。<br>• **开机后台播放改用 `startService`**：原先用 `startForegroundService`，而系统要求 5 秒内调起 `startForeground()`；冷启动时「读库 + 建 MediaController」在模拟器上就超过了这个时限，复现出 `Context.startForegroundService() did not then call Service.startForeground()` 的 ANR（真机更慢）。`BOOT_COMPLETED` 接收器本身带临时白名单，直接 `startService` 即可，通知由 Media3 起播时自己贴。<br>• 单测 313 → **316 项**；lint 0 Error。<br>• 本版**不重建数据库**（schema 仍为 v5）。 |
