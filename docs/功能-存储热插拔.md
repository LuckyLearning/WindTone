# 功能 · 存储热插拔感知

> 合入：**main**（本晚连续交付）  
> 范围：可移动存储（U 盘 / SD）挂载后节流重扫；卸载时若正在播的曲落在已卸卷上，按播放错误同口径跳下一首或停住。

## 背景（规划实证）

车机歌多在可移动存储。原先全仓没有 `MEDIA_MOUNTED` / `StorageVolume` / `ContentObserver` 管插拔：

- 插入不重启 → 看不到新歌（只能手动「扫描」或等冷启动 AutoScan）。
- 拔掉正在播的曲 → 等 Media3 `FileNotFound` 才走 `ErrorSkipPolicy`，体感慢且无「存储已卸」语义。

`ExternalMedia.kt` 是外部 **Intent 打开音频文件**，不是热插拔。

## 怎么做的

| 层 | 类 | 职责 |
| --- | --- | --- |
| 策略 | `StorageHotplugPolicy` | 广播归类、`file://`→卷根、路径是否属卷、3s 重扫节流、卸载播放决策 |
| 总线 | `StorageHotplugBus` | `rescanRequests` / `unmountEvents` SharedFlow；挂载/卸载发重扫；卸载另发 unmount（节流只挡重扫，不挡 unmount） |
| 监听 | `StorageHotplugMonitor` | 动态注册 `MEDIA_MOUNTED/UNMOUNTED/EJECT/REMOVED/BAD_REMOVAL`（带 `file` scheme）；API 30+ 另挂 `StorageVolumeCallback.onStateChanged` 作车机 ROM 兜底 |
| 曲库 | `LibraryCore.startHotplugWatch()` | 收 `rescanRequests` → `scan(auto = false)`（与手动扫描同管道，绕过冷启动 10 分钟节流）；正在扫 / `ScanScope.UNSET` 则忽略 |
| 播放 | `PlaybackEngine.handleStorageUnmounted` | `decideUnmountPlayback`：曲在该卷且队列 > 1 → 跳下一首；否则 pause + 提示 |

接线：

1. `MusicApp.onCreate` → `step("storage-hotplug") { StorageHotplugMonitor(this).start() }`
2. `LibraryViewModel.init` 在 `session.scope = viewModelScope` **之后**调 `startHotplugWatch()`（避免挂到随后被丢弃的临时 scope）
3. `PlaybackEngine` init 里 `StorageHotplugBus.unmountEvents.collect`

用户可见文案（`values` + `values-zh`）：

- `storage_unmount_skip` / `storage_unmount_next_hint`
- `storage_unmount_stop` / `storage_unmount_stop_hint`

经 `UserFacingCopy.ensureNext` 拼成「短原因。下一步：…」，与 A4 / ErrorSkip 一致。

## 卸载策略（与 ErrorSkip 对齐）

| 条件 | 动作 |
| --- | --- |
| 当前曲不在已卸卷（或无 path、仅有 `content://`） | 不动；靠随后重扫 `missingSince` 软删 + 若播失败再走 ErrorSkip |
| 当前曲在该卷且 `queueSize > 1` | Snackbar + `seekToNextMediaItem` + `play` |
| 当前曲在该卷且队列 ≤ 1 | `pause`、UI `isPlaying=false` + 停播提示 |

不另起扫描管道；不碰 Soft EQ。

## 单测

- `StorageHotplugPolicyTest`：归类、路径解析、属卷判定、节流/时钟回拨、卸载决策
- `StorageHotplugBusTest`：挂载节流、卸载双发、节流下仍发 unmount、空 path

硬件广播未上 Robolectric（Monitor 的 `handleBroadcast` 只是 Policy + Bus 薄封装，策略已用纯函数覆盖）。

## 如何验证（真机）

1. 曲库已选扫描范围；插 U 盘/SD → 约数秒内自动重扫，新歌出现（log：`热插拔触发重扫` / Diag `挂载`）。
2. 播 U 盘上的歌，拔盘（队列还有其它曲）→ 提示「存储已卸下，已跳过…」并切下一首。
3. 队列仅此一曲时拔盘 → 停住并提示重新插入后扫描。
4. 3 秒内连拔连插 → 重扫合并，不叠扫。

## 未做边界

- **仅 `content://` MediaStore 路径**：无法从字符串判卷归属 → 卸载时不主动跳歌，交给重扫软删 + 播放错误跳过。
- 不监听 `MEDIA_SCANNER_*` / 不写 `ContentObserver`（车机 ROM 差异大；挂载广播 + StorageVolumeCallback 已够最小可用）。
- 不改 `versionName`、不打 tag（发版由主会话统一，Actions 额度满时仍只推代码）。
- 不实现「拔盘后自动从队列剔除该卷全部条目」（重扫软删即可；队列侧靠播失败/卸载当前曲处理）。
