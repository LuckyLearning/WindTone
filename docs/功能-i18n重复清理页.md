# i18n 重复清理页（第 12 批）

把 **DuplicateCleanupScreen** 里重复歌曲清理页 chrome 的硬编码中文收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–11 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 12 批。

## 覆盖范围

- 规则说明长文案（`dup_rules`）
- 扫描中 / 开始扫描 / 空结果 / 重新扫描（`dup_scanning` / `dup_start_scan` / `dup_none` / `dup_rescan`）
- 发现 N 组 / 移出 N 首按钮（`dup_found` / `dup_remove_n`）
- 清除扫描结果（`dup_clear_results`）
- 确认弹窗标题 / 正文 / 确认按钮（`dup_confirm_*`）
- 保留 / 移出徽章与元信息行（`dup_keep` / `dup_remove` / `dup_meta`）
- 标题复用 `duplicate_cleanup`；返回复用 `cd_back`；取消复用 `cancel`

## 刻意未改

- **SheetsSong** / MainScreen 全家桶 / Aliyun 整包（留给更后批次）
- SoftEq / SoftEqSpike
- `versionName` / tag / release
- 并行中的存储热插拔（Storage*/MediaMount*/AutoScan*）

## 验证

- `./gradlew :app:compileDebugKotlin --offline`
- 人工扫：`DuplicateCleanupScreen.kt` 用户可见文案无残留中文硬编码（KDoc/注释除外）
