# 竞品调研 · 本地音乐播放器（通用层）

> 调研于 2026-11-04（在线资料：官方站点 / Play 商店更新日志 / 横评文章）。
> 与 [`竞品调研-车机音乐应用.md`](竞品调研-车机音乐应用.md) 互补：那篇管「车机生态入口」（汽水 / QQ音乐车机版、小迪语音、白名单），这篇管「本地播放器产品本身」的功能面。
> 结论先行：**听风与通用竞品的差距不在「有没有」，而在三处——智能歌单（统计已备而未用）、多播放队列、以及三个车机强相关点（音频焦点策略 / 车载蓝牙歌词 / 耳机适配档案）**。椒盐音乐（Salt Player）是定位重叠度最高的对标对象：本地、无广告、无联网依赖、minSdk 24、手机/平板/车机三端。

## 一、市场全景（2026）

| 类别 | 代表 | 招牌 | 与听风的关系 |
|---|---|---|---|
| 音频引擎型（发烧） | Poweramp、Neutron、Symfonium、Salt Player | Hi-Res / 参数化 EQ / 耳机补偿 / ReplayGain / 位完美输出 | **正面竞品**，EQ 与音质是主战场 |
| 纯本地零网络 | Musicolet、Oto Music | 无广告、无联网权限、多队列、轻量快扫 | 定位同类；Musicolet 的「无互联网权限」与听风同款卖点 |
| 开源可主题化 | Retro Music、Phonograph、PixelPlay | Material You 动态取色、纯黑 AMOLED、播放页卡片 | 视觉层参考 |
| 文件夹 / 文件型 | AIMP、Pulsar | 文件系统浏览、CUE、APE/DSD | 组织方式参考 |
| 聚合型 | Symfonium | Plex/Emby/Jellyfin/NAS/云盘、投屏、Wear OS/TV | **超出范围**（与本地零网络定位冲突） |
| 反面教材 | Lark Player | 广告 + 趋势信息流 + 崩溃 + 误杀后台 | 用户离开它的原因 = 听风的存在理由 |

## 二、逐个竞品档案

### Salt Player（椒盐音乐，com.salt.music）★ 重点对标

- 12.4.1-play（2026-10-07），14.7MB，minSdk 24 / targetSdk 37（与听风同 minSdk）。酷安百万级下载。
- **音频**：FLAC/APE/DSD/OPUS/WAV 全解码、32bit Hi-Res、音频直通（bit-perfect）、AAudio/Direct 输出、10 段 EQ、混响/低音、增强立体声、回放增益（1.17.0 才加，听风更早）、**SALT FX V4+ 内置 30+ 主流耳机专属适配档案**（AirPods/索尼/AKG…）。
- **歌词**：桌面歌词、悬浮窗歌词、**车载蓝牙歌词（经蓝牙发到车机屏/仪表）**、状态栏歌词（Flyme）、逐字动画、歌词辉光、双语翻译、本地 LRC + 在线匹配。
- **媒体库**：增量扫描、**文件夹黑名单**、文件夹浏览、听歌统计、标签编辑（Lyrico）、**假无损识别**、「安全移除→保护歌单歌曲」。
- **场景**：手机/平板/车机分别优化、Android Auto、DLNA 投屏、桌面小组件、A-B 循环、睡眠定时。
- **细节**：**音频焦点丢失策略可选**（保持音量 / 降音量自动恢复 / 暂停自动恢复，v12.2.1 新增）、封面取色流光主题。
- 与听风的直接对比：听风在**诊断包、无障碍看护、电池白名单、车机 DiLink 深度适配（横屏 / 语音听写 / 应用启动管理入口）**上是椒盐没有的；椒盐在**耳机档案、蓝牙歌词、假无损识别、DLNA、小组件、AAudio 直通**上领先。

### Poweramp

- 发烧标杆：Hi-Res 24bit/384kHz、10 段参数化 EQ + 独立低音/高音、立体声扩展、混响、**按输出设备分别记忆音效设置**（耳机 / 蓝牙 / 扬声器各一套）、ReplayGain、DSD/FLAC 全格式、自定义锁屏与通知。15 天试用 + 一次性买断。
- 可借鉴思路：**音效设置按输出设备分档记忆**（车机蓝牙 / 耳机 / 扬声器自动切对应 EQ 档案）——听风已有「车载音效档案 + 蓝牙自动车机」，差最后一层「按设备自动挂档案」。

### Symfonium

- 全能聚合型（本地 + NAS + 云盘 + 投屏 + Wear OS/TV），付费买断。通用层亮点：
  - **智能歌单 / 智能筛选**：「评分 >4 星且一个月未播」「指定流派 + 年代」等条件式歌单，实时更新；
  - **多播放队列**：多条队列并行、各自记忆速度/随机/进度；
  - **AutoEQ 耳机补偿**：按耳机型号自动套补偿曲线，多套 EQ 配置按设备保存；
  - **Magic crossfade**：按歌曲实际能量智能交叉淡化；
  - Android Auto 深度支持（语音控制歌单切换）。

### Musicolet

- 零广告零 IAP 零联网权限（与听风同款隐私姿态）。**多播放队列（最多 20 条并行，各自记忆进度）**、8 段 EQ、内置标签编辑、内嵌/LRC 歌词、文件夹级播放、M3U 双向导入导出。界面朴素是代价。验证了「多队列」是纯本地播放器最能打的差异化功能。

### Oto Music

- 免费无广告、大曲库快速加载、无缝播放、同步歌词、Chromecast、文件夹浏览、**干净的 Android Auto 集成**。Pro 解锁 EQ。是「默认推荐给普通用户」的免费档。

### AIMP / Pulsar / Retro / Phonograph

- AIMP：文件夹即曲库、CUE 整轨、APE/FLAC/OGG/MPC 全格式、免费无广告。
- Pulsar：Material 设计、标签编辑、无缝、ReplayGain、Pro 有 5 段 EQ + Chromecast。
- Retro Music：开源、十余种播放页卡片样式、动态取色、AMOLED 纯黑；**开发节奏已放缓、大库扫描偏慢**（开源竞品的常见衰退曲线）。
- Phonograph：极简 Material、无 EQ；2026 年靠 fork 链维持。

### Lark Player（反面教材）

- 常驻横幅 + 全屏视频广告、后台被激进省电策略杀死（小米/Realme/Oppo 集中报障）、扫描漏嵌套目录、歌词匹配偏英文、趋势流推社交内容而非本地音乐。**用户流失的每个原因都是听风的固定卖点**，其中「后台被杀」听风已有电池白名单 + 看护体系正面覆盖。

## 四、借鉴功能清单（2026-11-04 更新，唯一现行版）

优先级依据：① 吃不吃得到现有资产（越吃得到越先）；② 车机相关性（听风主战场）；③ 引入新权限/新数据模型的代价。

> **2026-11-04 收口**：本表 13 项已全部处理完毕 —— **9 项新做**、**3 项核实为已有**（桌面小组件 / Android Auto 描述符 / 文件夹浏览）、**1 项核对后不做**（交叉淡化）。随 v1.2.51 出包。逐项实现口径、入口、边界与单测见 [`功能-竞品借鉴落地.md`](功能-竞品借鉴落地.md)；两处与清单原设想不同：耳机档案做的是**两条听感曲线**（不做型号级 AutoEQ 库）、蓝牙歌词是**实验室开关**（默认关，真机验证后再转正）。
