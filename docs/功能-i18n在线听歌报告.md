# i18n 在线听歌报告（第 18 批）

把 **OnlineListeningReport**（`SettingsOnlinePage.kt`）相对本地报告的壳差异收进既有 i18n 体系，与第 16 批本地报告对称：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

在线报告**复用** [ListeningReportScreen] 版式与 `lr_*` 分区/统计文案；本批只抽出在线专属标题与空态（`olr_*`），并给 `ListeningReportScreen` 增加可选覆盖参数。

## 覆盖范围

### OnlineListeningReport / ListeningReportScreen 覆盖参数（前缀 `olr_`）

- 标题 `olr_title`（本地默认仍 `lib_listening_report`）
- 榜单空态 `olr_empty_plays`；曲线/时段空态 `olr_empty_listen`
- 设置「在线播放」入口此前已用 `lib_listening_report` + `listening_time_time_of_day` / `playback_history`（本批不重抽）
- Toast `no_playable_url_was_returned`、无题 `untitled` 已走 strings

### ListeningReportScreen API

- 新增可选：`title` / `emptyPlaysHint` / `emptyListenHint`（null = 本地 `lr_*` / `lib_listening_report`）
- `DayCurve` / `HourBars` 接收空态字符串，便于在线覆盖

## 刻意未改

- SoftEq / SoftEqSpike / 播放内核
- Aliyun 整包其它壳（目录/登录/错误码等可下一批）
- versionName / tag / release
- 统计计算（`AliyunTrackStore` / `buildListeningReport`）
