# i18n 车机曲库（第 15 批）

把 **CarLibraryScreen**（顶栏 / 左导航视图名 / 搜索占位 / 播放条无障碍文案）面向用户的硬编码中文收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–14 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 15 批。

## 覆盖范围

- 车机视图名：SONGS 用 `car_view_all_songs`（「全部歌曲」/ All songs）；其余复用 `view_albums` 等（`carViewLabelRes` → `carViewLabel`）
- 顶栏：本地音乐复用 `lib_title_local_music`；首数用 `plurals/lib_song_count`；搜索占位 `car_search_hint`；搜索 / 关闭复用 `cd_search` / `cd_close_search`
- 左导航品牌复用 `app_name`；阿里云盘 / 扫描范围 / 设置此前已走 `drawer_*`
- 播放条：收藏 / 上一首 / 播放暂停 / 下一首复用 `cd_favorite` / `cd_unfavorite` / `cd_previous` / `cd_play` / `cd_pause` / `cd_next`

## 刻意未改

- 空库整页 CTA（`LibraryEmptyHint` / `lib_lists_*` / `lib_setup_*`）此前已入库
- ListeningReport / LibraryStats（已第 16 批）/ SheetsScanScope（留给更后批次）
- Aliyun 整包 / SoftEq / SoftEqSpike / 播放内核
- versionName / tag / release
