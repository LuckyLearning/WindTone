# 观测补齐 + 后台存活引导（本轮四项）

> 版本锚点：随 **v1.2.46** 出包。来源是「A 档收口后还能做什么」的四项判断，
> 不是规划文档里的 B/C 档（那些需要真机 A/B 或用户明示）。

## ① 测试基线恢复：1405 项 0 失败

上游 v1.2.44 / v1.2.45 两版遗留 10 项红，三类根因，全部只改测试：

| 类别 | 数量 | 原因 | 处理 |
| --- | --- | --- | --- |
| i18n 后仍断言中文 | 7（`QueueManagerTest` 5 + `AliyunAndroidTest` 2） | 文案改走 `AppStrings.s()`，取值取决于设备语言；无限定符的 Robolectric 按 `values/` 英文兜底解析 | `@Config(qualifiers = "zh-rCN")` 把断言语言钉死 |
| 并行下载默认关后未开启 | 1（`ParallelRangeDataSourceTest`） | A11 把 `onlineParallelDownload` 改成默认关，`obtain()` 直接短路 | `setUp` 显式打开、`tearDown` 恢复并清 `Prefs` 缓存 |
| 两处「128MB」撞选择器 | 1（`SettingsScreenTest`） | A3 把默认档改成 128MB 后，行摘要与弹窗选项文案撞车，两节点都带 OnClick | 改成「先切 256MB 再切回 128MB」，每步待选文案唯一 |

**为什么先做这项**：每次改动都要人工比对「这 10 个红是不是原来那 10 个」，
它会持续拖慢后面每一次验证。

## ② malloc 段补四值，判「保留」还是「真占用」

v1.2.44 车机包 `libc malloc` 132MB、最大单段 79.9MB，但埋点只有 `Private_Dirty`
一个数，于是只能**推断**成「大头 = 解码/播放缓冲」。推断不是事实。

现在每段同时给：

```
· 脏 79.9 MB · 虚拟 81.2 MB · Rss 79.9 MB · Pss 79.9 MB  [anon:libc_malloc]
```

判读规则：脏页不足虚拟六成 → 更像**已 free 未归还**的分配器区域（jemalloc / Scudo
常只 `madvise` 不 `munmap`）；接近 → 是**实打实占着的对象**。

这个区分决定后续方向：真占用要继续找谁申请的；未归还则**减少业务侧分配根本无效**，
得考虑显式 trim 或换分配器行为。

## ③ 电池优化白名单提到可见位置

这一项以前只在「诊断与排障」页，而该页要**连点版本号 5 次**才解锁——出问题的用户找不到。

车机上没加白名单的后果很具体：Doze / 后台冻结一旦生效，播放与悬浮窗会在息屏后被
掐掉（「放着放着没声了」），且**不报任何错**。两次车机诊断包里这一项都是「否」。

新增「后台运行」分区（关于与更新页），一行状态 + 跳转，复用 `ForegroundAppDetector`
已有的三段候选 Intent 与动态发现。挂 `ON_RESUME` 观察者刷新——用户去系统设置勾完
回来时 Composable 不会重建，不刷新就会出现「明明加进去了界面还写着未加入」。

## ④ 冷启动：把已有数据用起来

`MusicApp.step()` 每一步本来就写了 `ok:<name>`，但 `PerfMarks` 只挑四个固定 stage
输出，其余全丢。现在按耗时列出全部启动标记。

另加 `MainActivity.attachBaseContext` 埋点 `activity:attach`：类加载发生在更早、埋不到，
但这一行是**分界线**——

- `attach` 就很晚 → 时间在系统侧（类加载 / dexopt），改我们的代码没用；
- `attach` 很早、`onCreate` 很晚 → 是我们的 `onCreate` 在拖，得继续拆。

## 验收（下次诊断包看这几行）

| 项 | 位置 | 期望 |
| --- | --- | --- |
| 启动各步耗时 | `[性能]` 段 | 出现 `ok:crash-log` / `ok:cover` … 与 `activity:attach` |
| malloc 四值 | `[内存]` 段 top3 段 | 脏 / 虚拟 / Rss / Pss 四个数 + 判读行 |
| 电池优化 | 设置 → 关于与更新 | 「后台运行」分区有状态；未加入时带 `!` 与跳转 |

单测：1405 项 0 失败；新增覆盖 `parseSmapsDetailed` 四值、段级判读两态、
`PerfMarks` 各步输出、关于页电池行。

## 不做

- 冷启动根因**不在这轮盲改**：先靠 ④ 拿到 `activity:attach` 再决定；
- 规划文档 B 档（B1+/B4/B5/B6）与 C 档仍需真机 A/B 或用户明示。
