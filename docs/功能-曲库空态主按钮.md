# 曲库空态主按钮（#13）

## 要解决什么

曲库为空时，歌曲 / 专辑 / 歌手 / 文件夹 / 歌单各页以前要么只有一段灰字，要么分组页完全没有下一步——用户不知道该「扫描」还是「加文件夹」。

## 行为

- **仅空库**（`library.songs.isEmpty()`）显示主 CTA；有曲时不显示（搜索无结果、分组偶发空、用户歌单为空仍走各自原文案）。
- 主按钮对齐真实入口，不造假：
  - 指定目录 → **添加文件夹**（`onImportFolder`）
  - 全盘且未授权 → **授予权限并扫描**（`onFullScan`，内部会走授权）
  - 全盘已授权 / 未指定但已授权 → **扫描音乐**（`onFullScan`）
- 次按钮一律 **扫描范围设置**（打开既有 ScanScope 面板）。
- 文案与按钮逻辑集中在 `resolveLibraryEmptyCta` + `LibraryEmptyHint`，歌曲列表 / 分组列表 / 歌单列表共用。

## 不做什么

- 不改 UNSET 时的首次 `ScanSetupView` 引导。
- 不新增独立「导入」假入口；导入文件夹就是指定目录主 CTA。
- 不重建数据库。

## 验证

- 单测 `LibraryEmptyCtaTest`：三种范围 × 授权组合。
- 真机：清空曲库后分别在「歌曲 / 歌手 / 歌单」看到同一主按钮；扫入歌曲后按钮消失。
