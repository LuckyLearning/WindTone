# 列表 / 通知位图路径对照（精确 px / ARGB）

## 对照结论

| 路径 | 入口 | 分桶 / 565 | 本轮 |
| --- | --- | --- | --- |
| 列表 / 播放页 / 车机 / 歌单四宫格 | `CoverArt` → `CoverRepository.cover` | `cachePxFor` + RGB_565（`ad21943` 已收） | 无需再改 |
| 通知 / 锁屏 `artworkData` | `downscaleForNotification` → `decodeScaled` | 565；**本轮按长边判定**，高压缩大图不再因 <64KB 跳过 | 修 |
| 桌面小部件 | `PlaybackService.decodeSmall` | 旧本地 `BitmapFactory` 默认 ARGB | → `decodeForWidget`（565 + `cachePxFor`） |
| 主题取色 | `ThemeColorExtractor` | 旧强制 ARGB_8888，缩略 ~48px | → `RGB_565`（`getPixels` 仍可读） |
| 扫码登录 / 悬浮名单图标 | 非封面 | ARGB 保留（需 alpha / 非封面缓存） | 不动 |

## 性能口径

- 小部件常驻 `WidgetState` 位图：ARGB→565 约减半像素字节。
- 通知：堵住「大边长 + 小文件」漏降采样，降低 MediaMetadata / Binder / 通知解码峰值。
- 取色：瞬时解码峰值减半；无常驻缓存、无新线程。
- 不碰 SoftEq / 播放热路径。

## 单测

- `CoverCacheTest`：非图小/大包；`WIDGET_COVER_PX` 分桶。
