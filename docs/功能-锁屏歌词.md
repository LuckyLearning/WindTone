# 锁屏 / 通知栏当前歌词行（H4）

播放中时，**系统通知栏**与**锁屏媒体卡**的第二行（SYNOPSIS / `MediaMetadata.description`）显示**当前歌词行**；没有可用时间轴歌词时回退为「标题 · 艺人」（艺人未知则只显示标题）。

## 行为

| 情形 | 展示 |
|---|---|
| 有同步歌词、已进入某句 | 该句正文（与悬浮歌词同一时间轴） |
| 间奏空行 | 回溯上一句非空歌词（同悬浮窗） |
| 前奏（未到第一句） | 「标题 · 艺人」，不把歌名再写进 SYNOPSIS |
| 无歌词 / 仅纯文本无时间轴 | 「标题 · 艺人」；并清空 description，通知栏回落默认艺人行 |

不依赖「桌面悬浮歌词」开关——锁屏歌词始终随播放进度更新。

## 实现要点

1. **时间轴**：`LockScreenLyrics` → `OverlayContentResolver.resolve`（不另造歌词引擎）。
2. **写入会话**：`LockScreenLyricPublisher` 在进度 ticker 里对当前项 `replaceMediaItem`，只改 `MediaMetadata.description`；文案去重。
3. **防切歌副作用**：`replaceMediaItem` 会触发 `onMediaItemTransition`；引擎见 `LockScreenLyricPublisher.isUpdating` 直接 return，避免清 A-B / 重载歌词 / 片头跳过状态。真切歌时 `reset()`。
4. **通知栏**：`LyricMediaNotificationProvider` 继承 `DefaultMediaNotificationProvider`，`getNotificationContentText` 优先用 description。

## 验证

- 单测：`LockScreenLyricsTest`（当前行 / 回退 / 前奏 / 间奏 / 偏移）。
- 真机：播一首带 LRC 的歌，下拉通知与锁屏应随句切换；无歌词曲目第二行仍为艺人。

本功能随 **v1.2.32** 发版；**不重建数据库**。
