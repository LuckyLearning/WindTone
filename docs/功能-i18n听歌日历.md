# i18n 听歌日历（第 6 批）

把 `ListenCalendarScreen.kt` 里面向用户的硬编码中文抽进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–5 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 6 批。

## 覆盖范围

- 页标题（`cal_title`；收听报告入口按钮同键）
- 返回 / 上月 / 下月 contentDescription（返回复用 `cd_back`）
- 加载中、色块说明脚注
- 本月合计 / 有听的日子 / 单日最多
- 周标签（`cal_week_labels` string-array）
- 日摘要空态 / 有收听 / 无记录

## 刻意未改

- SoftEq / EqSheet
- `formatListenDuration` / `formatYearMonth` / `formatCalendarDayTitle`（数据层中文格式，留给后续；单测仍钉中文）
- 侧钮顺序设置 / SceneChips（其它批次）
- `versionName` / tag / release
- 听歌日历聚合业务逻辑

## 验证

- `./gradlew :app:testDebugUnitTest --offline --tests com.luckylearning.windtone.data.ListenCalendarTest`
- 人工扫：`ListenCalendarScreen.kt` 无残留用户可见中文硬编码
