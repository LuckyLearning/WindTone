# i18n 诊断导出（第 11 批）

把 **SettingsDiagnosisPage** 里诊断导出 / 完整诊断页 chrome 的硬编码中文收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–10 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 11 批。

## 覆盖范围

- 无障碍页缺失提示与按钮文案（`diag_a11y_*`）
- 后台保活 / 电池白名单行（`diag_battery_*`）
- 诊断包（完整）行、弹窗标题、复制 Toast（`diag_pack_*`；按钮复用 `copy_all`）
- 一键取证行、弹窗、再复制 / 关闭（`diag_forensics_*` / `diag_close`）
- 车机排障报告（前台识别）行、弹窗、落盘路径、复制 Toast（`diag_probe_*`）
- 非官方安装提示、前台应用名括号、最近切过的应用 / 加入 Toast（`diag_unofficial_hint` / `diag_label_paren` / `diag_recent_apps` / `diag_added`；名单按钮复用 `in_list` / `add_to_list`）

## 刻意未改

- **SoftEq** 诊断行（「软 EQ 状态」标题 / 相位摘要 / Toast）— SoftEq 生产与 E5 诊断 chrome 本批不动
- `DiagnosticsReport` / `ForensicsScript` / `ForegroundProbe` **正文**（排障专用文本，按约定保持中文）
- `versionName` / tag / release
- 并行中的 `BtAutoCarPolicyTest.kt`

## 验证

- `./gradlew :app:compileDebugKotlin --offline`
- 人工扫：`SettingsSystemPages.kt` 的 `SettingsDiagnosisPage` 导出 chrome 无残留中文硬编码（注释与 SoftEq 行除外）
