# 悬浮窗前台包名防抖（v1.2.43）

## 动机

v1.2.40 车机诊断包可见：前台在 `com.byd.avc` ↔ 地图 / 听风 之间短切时，
隐藏名单命中会跟着抖，悬浮窗显隐狂闪。输入法已有忽略（v1.1.90），
但 avc / gesture / sr 等瞬切不是输入法，不能一律忽略——真开 360 仍要藏窗。

## 做法

1. **`ForegroundPkgStabilizer`**：候选包须连续稳定 `STABLE_MS`（450ms）才提交；
   时钟可注入，单测不 sleep。
2. **`OverlayStateBinder`**：隐藏判定订阅
   `currentPkg.distinctUntilChanged().debounce(foregroundStableMs)`，
   不再用原始瞬时包名；`ForegroundAppState.currentPkg` 仍即时（诊断 / 历史不变）。
3. 生产默认 450ms；单测 `OverlayStateBinder(..., foregroundStableMs = 0L)`。

## 未动

- SoftEq 主路径
- 隐藏名单语义（真停留在名单包仍会隐藏）
- 无障碍 / UsageStats 喂料通道

## 车上怎么验

1. 隐藏名单含 `avc`（或你车上的 360 包名），开悬浮窗在桌面 / 地图上显示。
2. 在听风与地图间来回切几下：窗不应跟着闪；短冒 avc 也不应闪藏。
3. 真正打开 360 并停留：约半秒内应收起；退出后恢复。
4. 诊断里「当前前台」仍应即时变，可与窗的显隐不同步一小段——这是预期。
