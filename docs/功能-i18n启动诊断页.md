# i18n 启动诊断页（第 10 批）

把 **BootDiagView**（纯 View 启动诊断页）面向用户的硬编码中文收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–9 批同一套约定，不另造框架。本页刻意不用 Compose，因此用 `Context.getString(R.string.boot_diag_*)`，不用 `stringResource`。详见 `docs/AI开发指南.md` § i18n 第 10 批。

## 覆盖范围

- 探针提示 / 标题 / 五种启动状态说明
- 分区标题：设备与系统、屏幕、系统栏 insets、窗口与显示、上一轮启动、最近崩溃
- 按钮：进入应用、复制全部；页脚提示；复制成功 Toast / 剪贴板标签
- 屏幕与窗口快照字段标签（像素 / dp / 方向 / 深色模式 / 刷新率 / 字体缩放 / 多窗口 / 画中画等）
- 截断后缀、无上一轮记录占位

## 扫后未选

- **曲库格式筛选**（`LibraryFormatFilterSheet`）：标题 / hint / 无损 / 扩展名分区 / 清空 **已**走 `lib_format_filter_*`，本批无需再改
- **设置 → 诊断与排障**里「诊断包 / 一键取证 / 车机排障报告」等导出 chrome：仍有硬编码，留给后续批次
- **DiagnosticsReport** 正文段（含 `[场景]`）：排障专用文本，按既有约定保持中文，非界面 locale

## 刻意未改

- `BootTrace` / `CrashLog` / 诊断构建开关等业务逻辑
- SoftEq / EqSheet / versionName / tag / release
- 并行中的 `UserEqPresetsTest`（EQ 导入导出单测）

## 验证

- `./gradlew :app:compileDebugKotlin --offline`（本页无独立 Compose 单测；资源化后靠编译与人工扫）
- 人工扫：`BootDiagView.kt` 用户可见字符串无残留中文硬编码（注释除外）
