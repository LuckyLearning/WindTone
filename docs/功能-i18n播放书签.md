# i18n 播放书签（第 5 批）

把 `BookmarkSheet.kt` 里面向用户的硬编码中文抽进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–4 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 5 批。

## 覆盖范围

- 播放书签 Sheet 标题（复用 `po_bookmarks`）
- 无曲目 / 当前位置摘要
- 「在此记书签」按钮
- 本曲书签空态与条数
- 跳转 / 删除（删除复用 `delete`）/ 关闭

## 刻意未改

- SoftEq / EqSheet
- ListenCalendar / 侧钮顺序设置（留给后续批次）
- `versionName` / tag / release
- BookmarkRepository 业务逻辑

## 验证

- `./gradlew :app:testDebugUnitTest --offline --tests com.luckylearning.windtone.data.BookmarkRepositoryTest`
- 人工扫：`BookmarkSheet.kt` 无残留用户可见中文硬编码
