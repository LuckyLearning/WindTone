# 资源占用极致：悬浮窗「字不变不重绘」

车机核心路径：歌词悬浮窗常驻。进度 tick 仍按时解析当前行（跟词不放慢）；
**文案 / 行角色 / 样式入参未变时**跳过 Window 文案重绘与无意义几何上报。

## 改动

1. **`OverlayRenderKey`**：纯函数去重键（形态、强调、正文色/底板/当前行色/压暗、各行角色+文案）。
2. **`LyricOverlayService.renderLines`**：先比键；相同则不计 Spanned / `setText`（仅必要时改 alpha），返回 `false`；真刷返回 `true`。`OverlayMetrics` 记「刷字 / 跳过」。
3. **`OverlayStateBinder`**：`appearanceRev` 进 paint 指纹；指纹未变（如仅前台包名防抖重入且内容相同）跳过 compose→render；几何上报跟显隐/标题/真刷字走。

## 有意未动

- 跟词节拍 / `OverlayContentResolver` 解析频率
- 前台探测与包名防抖窗口
- SoftEq 滤波核、交叉淡入、发版

## 车上怎么验

装本机包后：开悬浮窗长播 10～15 分钟 → 导出诊断包，看「刷字 N 次（跳过 M 次）」——跳过应远大于刷字；主观跟词不糊、不滞后。
