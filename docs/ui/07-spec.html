当前行高亮 = 颜色 × 字号 × 字重 × 底色四件事叠加：颜色 primary（非当前行 onSurface）、字号 17.5×scale（非当前行 15.5×scale）、字重 SemiBold（非当前行 Normal）、底色 primary 10%。
歌词精度只有「逐行」一种（v1.1.8 起）：KRC（酷狗）/ YRC（网易云）/ 增强 LRC 三种格式照读不误，但行内的字级标签（<start,dur,0> / (start,dur,0) / <mm:ss.xx>）一律剥离干净、时间轴只取行首，播放时按行滚动高亮 —— 直接把这几类文件丢进同目录即可，不必事先转成 .lrc。 ⚠️ 不要在这里加回字级数据：那要同时改「解析产出」与「渲染消费」两端（外加设置项），只做一半就是「有数据但没人消费」的死代码，而且不会报任何错。
车载模式：设置 → 外观 →「车载模式」开关（默认关）。开启后：① 启动应用直接进播放页（跳过库主页）并锁横屏；② 播放页歌词态 5 秒无触摸收起顶栏 + 控制键行 + 底部状态行，保留歌名行（含红心）+ 歌词 + 进度条 + 时间，触摸即恢复全部控件并重新计时；封面态不收起（封面本身是主要视觉）——此沉浸态手机 / 车机通用（⑫D）；③ 歌词字号放大：在用户设定的 scale 上再乘 1.5（正文 15.5→约 23sp、当前行 17.5→约 26sp）；④ 播放页不再单独限宽：车机横屏走 v3 壳（左导航 188px + 内容区），歌词在内容区里居中；沉浸态导航与控制键一起收起。见 ⑫D / ㊲ 屏。
桌面悬浮歌词：设置 → 歌词 →「桌面悬浮歌词」开关（默认关），播放页「播放设置」弹层的歌词分组里也有同一个开关。开启后由 LyricOverlayService（前台服务，foregroundServiceType="mediaPlayback"）在屏幕最上层挂一个 TYPE_APPLICATION_OVERLAY 窗口。
  只在 App 退到后台时显示（前台自动隐藏，避免与播放页歌词重复）；灭屏也隐藏（看不见还画是白耗电）。三个例外：调整位置、开启开关后的 6 秒预览、以及改外观设置后的即时预览。
  内容与排版：顶部可选两行小字「歌名 / 歌手」（v1.1.15，默认关；独立三档字号，与歌词字号互不影响，歌手缺失时只显示歌名一行）；歌词行数 1–5 行可调（当前行居中高亮，上下带上下文；偶数行时下方多一行）；窗内文字对齐居中 / 居左可配（居中默认；居左 = 每行左对齐起排）；只有该行有翻译时额外紧跟一行双语副行（小一号、同样压暗）；主角与上下句只靠「明暗 / 字重 / 字号」区分（整窗只有「文字颜色」一处可调，v1.1.8 起没有「已唱色」）。行切换带 120ms 淡入淡出。
  前奏 / 间奏不会让字幕消失：「还没到第一句」时回落显示歌名并把第一句作为下一句预告；遇到带时间戳的空行（间奏标记）时停在上一句并压暗——整窗消失会让用户以为功能坏了，这是被真机证实过的老问题。
  外观三档：字号 小 / 中 / 大（基准 20sp，最终宽度夹在屏宽 90% 以内）；底板 无 / 半透明 / 深色实底（默认半透明——「纯白字 + 投影无底板」在亮色壁纸上被证实看不清）；暂停时 淡出 / 隐藏。见 ㊴ 屏。
  两种模式：锁定态（日常）带 FLAG_NOT_TOUCHABLE，点击完全穿透；调整态（设置页「调整悬浮歌词位置」进入）摘掉该 flag 可拖动，2dp 蓝色圆角描边提示，松手落盘横纵坐标，点「完成调整」锁回穿透。调整态 60 秒无操作自动锁定并弹提示（否则用户忘了点「完成」会在桌面上一直留一条吃触摸的横条）。位置存 Prefs：横 lyric_overlay_x / 纵 lyric_overlay_y 都由拖动决定，默认横向居中、纵向「状态栏下方 + 64dp」（64dp 是实测让开荣耀桌面顶部媒体胶囊的值）。
  权限：SYSTEM_ALERT_WINDOW（比亚迪 DiLink 路径：设置 → 应用 → 权限 → 出现在其他应用上）。数据流为 播放域 → LyricOverlayBus（单例 StateFlow）→ Service，单向解耦，界面退出后 Service 仍独立存活；无 IPC，服务只读总线、不持有 ViewModel 引用（唯一的反向通道是「请求退出调整态」这一条一次性事件）。服务被系统杀掉后会在下一次切歌时自动重建（30 秒节流）。
车机版（横屏独立布局 · v3，2026-10-20）：目标 2560×1600px 中控屏（16:10，12.8~13"），实测密度 232~236dpi → hdpi(240) → 1707×1067dp 可用空间； 效果图画布 1000×625px 代表之（k≈0.5858，dp = px ÷ 0.5858）。布局 = 左常驻导航 188px + 内容区 + 底部常驻播放条（只铺内容区）； 导航在最底部留出车机 Dock 的 56dp 安全区（设置项不得贴到最底边——v1.1.14「设置点不到」的根因）。
  尺寸基准（效果图为视觉参考，代码以 dp 为准）：导航条目高 44px/≈75dp、图标 21px、文字 15.5sp； 列表行 72px/≈123dp、封面 56px、歌名 19sp、副标题 13.5sp；播放条 92px、封面 56、控制键 48 / 主键 62；专辑网格 6 列、封面方形（≈196dp）。
  封面缺省色块：无内嵌封面时用「标题首字 + 六档渐变」，按 Song.stableKey 哈希取档（同一首永远同色）， 六档 #8B7CF6→#5040D8 / #FB7185→#E23D5A / #5AA9F8→#2F76E8 / #3ED6A8→#0E9E8F / #FBBF4A→#EF7C1A / #F472B6→#A855F7，白字对比均 ≥4.5:1。
  导航图标带语义色、文字中性：全部歌曲 primary / 专辑 #E8793B / 歌手 #7C6BF0 / 文件夹 #3B82C4 / 歌单 #17A398 / 设置 onSurfaceVariant。 颜色令牌与手机版共用；不得把手机竖屏布局拉宽充当车机版。
播放页配色：整页垂直渐变 = lerp(background, primary, 0.32) → lerp(background, primary, 0.10) → background（必须不透明混色，不能用半透明，否则会透出底层列表）。
图标尺寸：抽屉项 22 · 顶栏按钮 24 · 上一首/下一首 34 · 播放主键 34（按钮 66）· 缩略操作 20 · 字母索引 9。
v1.1.3 结构变化：① 手机版底部五视图导航整体移除，改为顶栏汉堡按钮 + 侧边抽屉（宽 280dp、右缘圆角 28dp、遮罩收起；「更多」组三个入口与顶栏 ⋮ 菜单同目的地）；② 设置主页改为二级分类入口卡（CategoryRow：40dp 图标容器 + 标题 + 摘要 + chevron），外观 / 播放 / 歌词下沉为子页，全部分类两级直达。车机版左导航不受影响。

七·B、视觉升级层（设计规范 v2）

在 M3 / Indigo 令牌之上叠加 · 2026-10-20
品牌概念「声随风动」：主色保持 Indigo #5B4BE0，新增 风之渐变（靛 → 紫 → 青，--grad-brand）作为唯一「品牌签名」，仅用于：激活态导航 / 主播放键 / 封面光晕 / 进度填充 / 品牌标记。页面底色加一抹径向风之渐变光晕，避免死板纯色。
风之渐变令牌：--grad-brand: linear-gradient(135deg,#5B4BE0,#8B5CF6 48%,#22D3EE)；光晕 --wind-glow（顶部 16% primary 径向）。
玻璃拟态：迷你播放条 / 顶栏 / 侧边抽屉 / 底部弹窗 / 菜单 / 对话框 / 车机常驻条，统一半透明 + backdrop-filter: blur + 彩色描边 --glass-bd。深色 rgba(28,26,37,.90)、浅色 rgba(255,255,255,.94)（2026-10-22 用户反馈透明度太高压不住底下内容，整体上调）。。
层级投影（靛蓝 tint）：--sh-1/2/3 三级取代原中性灰阴影，悬浮即有品牌色漫反射。
统一动效：缓动 --ease: cubic-bezier(.2,.8,.2,1)；时长 --dur-1 .18s / --dur-2 .26s / --dur-3 .4s。歌词 120ms 淡入、封面呼吸/旋转、播放键按压回弹，全部 prefers-reduced-motion 兜底。
页面转场（v1.2.9 起）：层级之间的下钻 / 返回统一横向滑动 —— 新页从前进方向推入（下钻从右、返回从左），旧页向反方向退出 1/4 屏宽并淡出（--dur-2）；容器顶栏标题只做 --dur-1 淡入淡出。方向由页面层级深度决定，不设"前进/后退"标志位。实现集中在 ui/SettingsMotion.kt，业务页不得自写时长。
图标风格：24dp 光学方格、2px 圆角描边（stroke-linecap:round）、currentColor 着色；同簇不混用实心/空心，视觉权重统一。生产 App 采用描边集（见下方 do / don't）；文档站 glyph 为 Material fill 集（保真原型，.ic{fill:currentColor}）。
交互反馈五态：默认 / 悬停（底色 +10% on-bg）/ 按下（缩放 .88~.97 + 底色 +16%）/ 焦点（3px 靛蓝环 --ring）/ 禁用（opacity .4）。列表行悬停微抬升 1px。
无障碍：≥44dp 触控、3px 焦点环、200% 缩放、正文/背景过 WCAG AA（既有令牌已满足）。
落地点：改视觉只改 ui.css 顶部令牌与「视觉升级层」，勿在分章写内联样式；发布前真机核对玻璃模糊性能（车机低端屏可降级为不透明）。
