六、车机版（2560×1600 中控屏）

v3 布局（2026-10-20）· 左常驻导航 + 底部播放条 · 1707×1067dp 基准
本版方向：左常驻导航 + 内容区 + 底部常驻播放条。2026-10-20 用户给出一张参考图并拍板「车机按这种布局来」， 于是把 v1.1.19 的「单栏 + 顶部横向 Tab」改回左侧导航—— 但不是恢复 v1.1.14 被否决的那套两栏：导航收窄到 188px 并卡片化、播放条只铺右侧内容区、Dock 安全区照留， 三点差异写在第 ㊱ 屏的说明里。
页面顺序：㊱ 音乐库（最近播放）→ ㊱B 专辑网格 → ㊲ 播放页（歌词态）→ ㊳ 设置 → ㊴ 桌面悬浮歌词（四态）。 v1.1.19 的单栏方案（㊱B / ㊲B）与 v1.1.32 的「一页到底」设置（㊵）已被本版吸收，不再单独出图。
目标设备：2560×1600 px 中控屏（16:10，12.8~13 英寸）。按实测密度 232~236 dpi 落到 hdpi(240) 密度桶， 换算可用空间约 1707×1067 dp（约为手机 360dp 宽的 4.7 倍）。
本页画布：1000×625 px 代表 1707×1067 dp，换算系数 k ≈ 0.5858（写成 dp 时 = 画布 px ÷ 0.5858，或直接看标注）。
与手机版的关系：不是把手机竖屏拉宽，而是独立的横屏两栏布局；仅复用颜色令牌、图标与全屏播放页。
