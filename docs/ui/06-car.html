六、车机版（2560×1600 中控屏）

v1.1.32 · 单栏大控件 · 1707×1067dp 基准（㊱B / ㊲B / ㊵ 为当前方案，㊱~㊳ 为历史两栏）
本版方向：单栏 + 大控件 + 免手势。v1.1.14 停用车机两栏后，车载模式只剩「直进播放页 / 锁横屏 / 5 秒收起 / 歌词 ×1.5」， 实测反馈是开关拨了感觉没区别。这一版把车机界面重新做成单栏（不做左右分栏，用户否决仍然有效）， 宽屏余量全部用来放大控件，并把「开关即刻生效」一并补上。 设计说明见 《车载模式重设计 · 单栏大控件》。
目标设备：2560×1600 px 中控屏（16:10，12.8~13 英寸）。按实测密度 232~236 dpi 落到 hdpi(240) 密度桶， 换算可用空间约 1707×1067 dp（约为手机 360dp 宽的 4.7 倍）。
本页画布：1000×625 px 代表 1707×1067 dp，换算系数 k ≈ 0.5858（写成 dp 时 = 画布 px ÷ 0.5858，或直接看标注）。
与手机版的关系：不是把手机竖屏拉宽，而是独立的横屏两栏布局；仅复用颜色令牌、图标与全屏播放页。
⚠️ 以下 ㊱~㊳ 为历史设计（1.0.3~1.1.13 的车载两栏），v1.1.14 起停用： 原因见《版本历史》1.1.14 —— 车机固定按钮栏压住左下角「设置」，且用户明确不要双栏。 CarHomeScreen.kt 保留但不再被调用（LayoutContractTest.noTwoPaneLayout 盯着）。 保留它们只为对照，不要照着改代码。
