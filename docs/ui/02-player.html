二、播放页

PlayerScreen.kt · PlayerScreenParts.kt · LyricsPane.kt —— 歌词态 / 封面态 / 音量浮层 / 暂无歌词 / 纯文本 / 沉浸态（手机 + 车机）
左右滑动切歌（2026-10-27）：中部内容区（歌词 / 唱片）左滑 → 下一首、右滑 → 上一首。 手指拖动时这一层跟着平移一小段（阻力 0.45、上限屏宽 1/6），松手没过阈值就弹回 —— 有这一步 用户才知道「这一划被认了」，否则歌变了、屏幕上什么都没发生。阈值取屏宽 12%，或者甩得够快 （900px/s）也算 —— 行车中手指划不长，只认位移会让人觉得「划了没反应」；两者方向冲突时以位移为准 （甩出去又拉回来，本意就是不切）。
手势只挂中部，不挂整页：底部进度条本身就是横向拖动，挂整页必然抢手势；中部歌词区是纵向滚动， 与横向手势方向互斥，不会互相打岔。判据与参数集中在 PlayerSwipe.kt（纯函数，有单测）。
