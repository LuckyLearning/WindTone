用模拟器验证效果图

不依赖 SDK 也能打开本页；下列命令在仓库根目录执行（Git Bash）
目标：HTML 效果图是设计基准；AVD 用来核对 Compose 实机布局是否跟上。
Windows：用 C:\Program Files\Git\bin\bash.exe 跑脚本。加 --window 会弹出模拟器窗口。
注意：模拟器不能验证厂商 ROM 悬浮窗拦截与真实 EQ 听感——那两项仍需真机。
phone手机 AVD · wt_phone 对照章节：01–05、08–10（手机框） 
bash scripts/emulator.sh create wt_phone
bash scripts/emulator.sh start wt_phone --window
bash scripts/emulator.sh wait wt_phone
# 安装 debug 包后点选对应页面
bash scripts/emulator.sh shot wt_phone docs/ui/_shot-phone.png
bash scripts/emulator.sh stop wt_phone
