# 快进 / 快退 ±10s / ±15s（N2）

> 落地日：2026-10-31（Asia/Shanghai）
> 版本：随 **v1.2.24** 发版

## 干了什么

播放页进度条下方提供 **−15 / −10 / +10 / +15** 四个按钮，一点按相对当前位置跳转对应秒数。

- 走既有 PlayerActions.seekBy → QueueManager.seekBy → 与 seekTo 同一 Media3 seek 路径。
- 目标位置由纯函数 SeekJump.target 夹到 **0～duration**；时长未知（≤0）时只能落到 0。
- **手机完整态**显示；**沉浸态**与**车载模式**不重复（车机 / 通知栏 / 方控已有系统 seek）。

## 怎么干的

1. **纯函数** SeekJump：PRESET_SECONDS = [10, 15]、deltaMs、	arget(position, duration, delta)。
2. **引擎** QueueManager.seekBy / PlaybackEngine.seekBy / PlayerActions.seekBy。
3. **UI** SeekJumpButtons（PlayerScreenParts）；PlayerScreen 在时间行下渲染；MainScreenParts 接线 playerVm::seekBy。
4. **单测** SeekJumpTest：预设、正负跳转、越界夹紧、未知时长、负进度。
5. **文档**：本页 + 功能说明.md 播放页一条；发版写入 版本历史.md。

## 怎么验

1. 播一首 ≥1 分钟的歌，进播放页：进度条下应见 −15/−10 与 +10/+15。
2. 在约 0:30 处点 +10 → 约 0:40；点 −15 → 约 0:25。
3. 在开头点 −15 → 停在 0:00；在结尾附近点 +15 → 停在曲末。
4. 车载模式打开：播放页**不应**出现这四个按钮。
5. ./gradlew :app:testDebugUnitTest --tests com.luckylearning.windtone.playback.SeekJumpTest

## 不做什么

- 不做「设置里改默认秒数」单档模式（本版选双按钮 ±10 / ±15）。
- 不往通知栏 / MediaSession / 车机方控再挂一套自定义增量（系统已有 seek）。
- 不在歌词面板另做快进快退（旧死符号 seekBy 曾因此被删；现恢复的是播放页路径）。
