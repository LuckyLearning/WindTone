# 功能说明

> **发版状态**：用户可见积压已随 **v1.2.37+** 出包；近锚 **v1.2.42 / v1.2.43**。细则见 [`待发版积压.md`](待发版积压.md)。真机勾选见 [`真机验证清单.md`](真机验证清单.md) §5。

## 音乐库

- **默认不扫描全盘**：安装后停在「选择音乐位置」页，由用户明确指定扫描范围（可在库页左上角胶囊标签或 `⋮` 菜单随时切换）：
  1. **扫描全盘** —— 读取系统媒体库（MediaStore）里的全部音频；若已授予「所有文件访问权限」，会额外做深度文件扫描，连带匹配同目录 `.lrc`
  2. **指定目录** —— 通过 SAF 只扫描用户挑的若干文件夹，可随时追加 / 移除；不需要任何存储权限
- 三个来源自动合并去重（媒体库 / SAF 目录 / 深度扫描），同一首歌优先保留带歌词、时长完整的那条
- 搜索（歌名 / 歌手 / 专辑 / 文件名），支持**拼音全拼与首字母**（如 `zf` 命中「周杰伦」）
- **曲库空态主按钮**（#13）：歌曲 / 专辑 / 歌手 / 合辑艺人 / 流派 / 年代 / 文件夹 / 歌单在空库时显示同一主 CTA（扫描音乐 / 添加文件夹 / 授权扫描），有曲不显示；见 `功能-曲库空态主按钮.md`。
- **多碟专辑（G3 / ≥ v1.2.37）**：专辑详情按 **discNumber** 分区显示「碟 1 / 碟 2…」，曲目排序 disc → track；无碟号时行为不变。Prefs 缓存、不重建库。见 [功能-多碟](功能-多碟.md)。
- **流派 / 年代浏览（G1）**：按元数据流派与发行年分组，点组即播；无标签归「未知」；Prefs 缓存、不改 Room。见 [功能-流派年代浏览](功能-流派年代浏览.md)。
- **合辑艺人浏览（G2）**：按 Album Artist 分组（优先 albumArtist，回退 artist）；合辑正确归组；Prefs 缓存、不改 Room。见 [功能-AlbumArtist合辑](功能-AlbumArtist合辑.md)。
- **搜索历史**（最近 10 条，搜索框空态显示，可一键清空）
- **搜索框语音听写（2026-10-27）**：输入框右侧的麦克风，说一句直接搜 / 起播 —— 车机上打字成本高，这是「语音点歌」在不接入车机语音通道时的平替。优先调系统语音识别，本机没有识别服务时退回「聚焦输入框 + 弹键盘」并提示改用输入法的语音键。只在搜索态出现，点一次录一次，不后台收音
- **格式筛选（H5）**：顶栏调音图标可「仅无损」和/或按扩展名（flac/wav/mp3…）多选，两维取交集；状态持久化；与格式统计页口径一致（m4a 非无损）。见 `功能-曲库格式筛选.md`。
- 6 种排序：标题、歌手、专辑、时长、添加时间、文件名。**排序按视图各记各的**，且每个视图只列自己适用的那几项（如文件夹视图没有「专辑」）
- **顶栏左侧的汉堡按钮拉出侧边抽屉**切换八种视图：歌曲 / 专辑 / 歌手 / 合辑艺人 / 流派 / 年代 / 文件夹 / 歌单；在内容区任意位置**从左往右滑**也能拉出。抽屉分两组（八个浏览视图 + 扫描范围 / 设置），**重启后停留在上次的视图**。**「设置」只有这一个入口**（顶栏 `⋮` 菜单里不再挂），**「检查更新」只在设置 → 更新里**
- **A–Z 字母索引导航条**，按标题首字拼音定位
- **「回到当前播放」浮动按钮**：当前曲目滚出屏幕后一键跳回
- **每行右侧 `⋮` 更多入口**（长按同样可用），不必先发现长按手势
- **批量多选**：长按任意一行进入多选，之后点行即勾选；支持全选 / 反选，可批量**加入歌单、收藏、加入播放队列、移出曲库、删除文件**
  - 删除走**系统的一次确认框**（一次请求涵盖所选全部文件），不会逐首弹窗；只清掉真正删成功的那批，没删成的留在原地 —— 不会出现「删了一半、界面还不知道」的状态
- **文件夹视图支持删除歌曲文件**：`⋮` →「删除歌曲文件」，媒体库文件走系统确认框，SAF 目录与深度扫描路径直接删，同名 `.lrc` 一并删除
- **排除目录**：文件夹视图里可把某个导入目录标为「已移出」——它扫出来的歌不再进曲库，但**重扫不会把这个标记收回**（这是「用户主动移出」，与「文件此刻不在」的软删严格区分），设置页可一键恢复
- **歌单系统**：新建 / 重命名 / 删除 / 加入 / 移除 / 播放全部；**拖动排序**、**一键去重**（按「歌名 + 歌手 + 时长」判定，只移出歌单、不删文件）、**把当前播放队列存成歌单**；固定入口「最近播放」「最近添加」「最常播放」「我的收藏」
- **歌单列表封面四宫格**（v1.2.16）：行左侧用前 4 首封面做 2×2 拼图；只有 1 首时整图；空歌单仍用占位图标；虚拟歌单（最近播放 / 最近添加 / 最常播放 / 我的收藏）同规则。格内走现有封面缓存，详见[设计 · 歌单封面四宫格](设计-歌单封面四宫格.html)
- **收藏**（行尾 `⋮` 或长按歌曲 → 底部操作抽屉；批量多选里也能一次收藏一批）
- **曲库持久化**：扫描结果落 Room 曲库，冷启动先出列表秒开，再后台按已选范围增量刷新；文件暂时不可见只标记软删，收藏与歌单不受影响
- **骨架屏占位**：扫描期间显示 8 行微光占位条，而不是一个转圈
- **播放统计**：播放次数、累计收听时长、听过的歌曲数（设置页可清空，收藏保留）
- **收听报告**：近 **7 / 30 天**的每日收听曲线、**24 小时时段分布**与 TOP 榜单；另附「已移出曲库」数量与一键恢复
- **听歌日历**：收听报告入口进入月视图热力色块（按日听歌量）；点日看摘要。复用 `listen_log` 小时桶，见 [功能-听歌日历](功能-听歌日历.md)
- **格式与容量**（设置 → 音乐库）：按格式统计曲库的首数与占用（占比条 + 平均码率），并给出**无损 / 有损**的拆分、合计占用、总时长与平均每首大小。只统计当前可见的歌，占用按文件大小累加；读不到大小的歌只计首数并单独提示条数。`m4a` 可能是 ALAC 也可能是有损 AAC，按扩展名分不出来，统一计入「有损」
- **元数据 Prefs 侧缓存**：流派/年代/专辑艺术家/碟号不进 Room，落 prefs JSON；曲库落地时按当前库 prune 并硬上限 2 万条（见 [功能-元数据Prefs侧缓存裁剪](功能-元数据Prefs侧缓存裁剪.md)）。
- **封面磁盘命中对照**：缓存边长分桶 + 诊断包 hits/miss/命中率（见 [功能-封面磁盘命中诊断加固](功能-封面磁盘命中诊断加固.md)）。
- **歌单 M3U 导入/导出**：用户歌单可导出为 M3U；导入时按本机 path/文件名/`#EXTINF` 标题匹配新建歌单。读盘与匹配走 IO，正文 ≤1 MiB、命中 ≤2000（见 [功能-歌单M3U导入](功能-歌单M3U导入.md)）。
- **在线歌单**（设置 → 音乐库 → 在线歌单，v1.1.37）：填 m3u / m3u8 / pls 直链即可播放，不需要下载。解析支持 `#EXTINF` 标题与时长、`tvg-name` 兜底、`Artist - Title` 拆分、相对路径；HLS（`.m3u8`）整条流作为一项播放。抓取时先按 UTF-8 解码、失败回退 GB18030（中文清单不乱码），响应体上限 4 MB；抓不到内容或返回网页时不会入库，并直接说明原因。
  在线条目走**独立队列**：不进曲库、不参与扫描与「清理失效歌曲」，也没有歌词与封面（远程地址没有本地文件）。
  播放过的在线音频会缓存到本机（v1.1.38，上限 512 MB、按最近最少使用淘汰），重播不再走网络；占用与清理入口在「设置 → 关于与诊断 → 在线缓存」。本地文件不经过缓存层。<br>
  当前正在播放的在线歌曲会按 5 段同时下载（v1.1.47，不限速，服务器不支持分段时自动退回单连接），这是首播提速的主要手段；暂停/切歌即停止并删除临时文件。<br>
  当前曲缓冲领先 20 秒后，会自动用最多 2 个连接把**接下来两首**先拉进缓存（v1.1.46，每个连接限速 320 KB/s，暂停时也会继续），所以切歌基本不用再等。实时状态与「立刻停止」入口在「设置 → 关于与诊断 → 后台预取」。
- **音频信息**：`⋮` →「音频信息」，读容器 / 编码 / 码率 / 采样率 / 声道 / 位深 / 时长
- 列表显示内嵌封面、标题、歌手、时长，并标注歌词来源；**内嵌缺失时回退同目录** `folder.jpg` / `cover.jpg` / `AlbumArt.jpg`（v1.2.23，见 [功能-folder封面](功能-folder封面.html)）
- 歌曲信息本地编辑（**只覆盖显示，不修改原文件**）

## 格式支持

| 容器 | 说明 |
|---|---|
| MP3 / MP2 | 全支持 |
| FLAC | 全支持（无损） |
| WAV | 全支持 |
| M4A / AAC | 全支持 |
| OGG / OGA | Vorbis 全支持 |
| OPUS | 全支持 |
| AMR | 全支持 |
| WMA / APE / DSF / TAK / TTA | 内核不支持，扫描时跳过并计数提示 |

> 解码由 Android MediaCodec + Media3(ExoPlayer) 完成，无需额外的第三方解码库。

## 歌词

### 取词优先级

逐级回退：

1. **同目录歌词文件**（`.lrc` / `.txt` / `.krc` / `.yrc` 都算，后两类见下文「格式兼容」）
   匹配规则（大小写不敏感）：
   - `歌名.lrc`
   - `歌名 - 歌手.lrc`
   - `歌名.zh.lrc` / `歌名.sc.lrc` / `歌名_xxx.lrc`
   - `歌名.txt`（纯文本歌词，无时间轴也能显示）

   同一首歌若有多份候选，**完全同名**优先；同为「带后缀的变体」时按扩展名取 `.krc` / `.yrc` > `.lrc` > `.txt`。
2. **同目录 `.txt` 歌词**
3. **音频内嵌同步歌词** — ID3v2 `SYLT` 帧（毫秒制时间戳）
4. **音频内嵌歌词**
   - MP3：ID3v2.2/2.3/2.4 的 `USLT` 帧、`TXXX:LYRICS`
   - FLAC：`VORBIS_COMMENT` 中的 `LYRICS` / `UNSYNCEDLYRICS` / `UNSYNCED LYRICS` 等
   - OGG / Opus：`\x03vorbis` / `OpusTags` Vorbis Comment
   - M4A / MP4：`moov.udta.meta.ilst.©lyr`

取出后按下表确定解析器：

| 文件 | 解析器 | 能力 |
|---|---|---|
| `.lrc` | `lyrics/LrcParser.kt` | 时间轴、多标签、元信息、offset、增强 LRC 的 `<mm:ss.xx>` 标签（剥离） |
| `.krc`（酷狗） | `lyrics/KrcParser.kt` | 16 字节密钥 XOR + zlib 解密 → 行时间轴 |
| `.yrc`（网易云） | `lyrics/KrcParser.kt` | 行时间轴 |
| `.txt` | `LrcParser.plainText` | 无时间轴纯文本 |

### 解析能力

- 时间轴 `[mm:ss]`、`[mm:ss.xx]`、`[mm:ss.xxx]`、`[mm:ss:xx]`，一行多时间标签
- 元信息 `[ti:]` `[ar:]` `[al:]` `[by:]` `[offset:]`（offset 会自动换算）
- **逐行同步歌词**：KRC / YRC / 增强 LRC `<mm:ss.xx>` 都能读，行内的时间标签会被剥离干净，按行切换高亮
- **双语歌词**：同一时间戳（差 0～50ms）的相邻两行自动合并为「主行 + 翻译副行」，**固定显示原文 + 译文**（v1.2.2 起移除了三档切换，见版本历史）。
  只影响显示，导出的 LRC 仍带完整翻译；日文假名 / 韩文谚文不算中英文，日文歌 + 中文翻译这种最常见的场景不会选错行。
- **编码嗅探**：BOM → UTF-8 严格校验 → GB18030 严格校验 → 兜底宽容解码。
  因此 UTF-8 / GBK / GB18030 / UTF-16 的歌词文件都能正确显示，不会乱码。

### 歌词界面

- 有时间轴 → 自动居中滚动、当前行高亮放大、**点击任意一行跳转到该时间点**
- 手动滑动时自动暂停跟随 4 秒，避免「抢滑」
- 调整**歌词偏移**（±0.5s 步进、可重置）与**字号缩放**；偏移**按歌曲分别记忆**
- **长按歌词里任意一行 →「就唱到这句」**：以该行为基准一次性算好整首的偏移（不用拿 ±0.5s 反复试探），弹窗里也能一键重置为 0
- 歌词面板与封面态的切换**会记住**，下次进播放页还是你上次看的那一面
- 可把当前歌词**导出为 `.lrc`**
- 无时间轴 → 居中纯文本滚动显示；无歌词 → 明确提示获取方式

### 歌词来源的格式兼容

歌词有三种落点：**同名文件**（`.lrc` / `.txt` / `.krc` / `.yrc` 放在音频同目录，命名匹配规则见上文）、**音频内嵌独立歌词**（ID3v2 `USLT` / Vorbis Comment / `©lyr`）、**音频内嵌同步歌词**（ID3v2 `SYLT`）。

`.krc`（酷狗）与 `.yrc`（网易云）这两种「逐字歌词」格式**仍然完整支持**——文件会在加载时解密解压、剥掉行内的时间标签，然后当作**普通同步歌词**参与滚动与高亮。也就是说：**直接用这两种文件即可，不需要事先转成 `.lrc`**；只是它们自带的字级时间信息不会被使用，当前行是整行高亮而不是逐字点亮。

### 锁屏 / 通知栏歌词（H4）

播放中时，系统通知栏与锁屏媒体卡显示**当前歌词行**（与悬浮歌词同一时间轴）；无可用同步歌词时回退「标题 · 艺人」。不依赖悬浮窗开关。详见 [功能-锁屏歌词](功能-锁屏歌词.md)。

### 桌面悬浮歌词

> Android 8.0+，需要「显示悬浮窗」授权。

- **侧钮上下顺序（v1.2.17+）**：车载模式下侧钮（收起 / 播放暂停 / 打开播放页 / **无障碍状态**）可在设置里上移下移调整竖直顺序；默认末尾为无障碍。**绿 = 无障碍真的在运行**（开关勾着 + 服务在案），红 = 未开或已掉；点按跳系统页（与播放页同通道）。**无障碍钮三档显示（2026-10-31）**：常显 / **仅未开启时显示** / 不显示 —— 选中间那档，正常工作时侧栏少占一块，服务掉线时它自己回来。详见[功能 · 侧钮顺序设置](功能-侧钮顺序设置.md)、[功能 · 侧钮无障碍状态](功能-侧钮无障碍状态.md)。

- 退到桌面 / 导航页后，在屏幕最上层显示当前歌词行；App 在前台时自动隐藏（避免与播放页歌词重复），灭屏也隐藏
- **顶部可选显示「歌名 / 歌手」两行小字**（v1.1.15）：默认关闭，字号单独三档（小 / 中 / 大），与歌词字号互不影响
- **歌词行数 1~5 行可调**：当前行居中高亮，上下带上下文（3 行 = 上下各 1，5 行 = 上下各 2）
- 当前行有翻译时自动附一行**双语副行**；当前行最亮最粗、上下句压暗，靠明暗区分主角
- **字号**（小 / 中 / 大）、**水平对齐**（居中 / 居左）、**底板**（无 / 半透明 / 深色实底；选「无」时自动加硬描边并提高上下句亮度，浅色画面上仍可读）、**暂停表现**（淡出 / 隐藏）、**宽度**（占屏宽百分比，默认 80%）都可调，改完立刻给一次预览
- **位置完全由拖动决定**：横向纵向都能拖，与排版互不干扰（「居中 / 居左」只管歌词在窗内怎么排，不会去动窗口的位置）；**调整态 60 秒无操作自动锁定**，锁定态**完全点击穿透**，不挡桌面与导航操作
- 前奏回落显示歌名、间奏停在上一句并压暗 —— 字幕不会突然消失
- 「歌曲被系统杀掉后」会在下一次切歌时自动重建服务，长途导航不必重开 App
- **全屏这一档不会盖住设置页**（v1.1.22）：整屏歌词只在桌面 / 导航页出现，App 内（含调整态与改完配置的 6 秒预览）一律不画 —— 否则它会压住宽度滑块与位置按钮，一边调一边看不见自己调的是什么。设置页改用一块 16:9 **缩略示意图**实时反映宽度与位置，实际效果以桌面为准
- 设置页提供**一键自检**：授权 / 开关 / 服务 / 窗口 / 位置 / 内容 / 外观一次测完并直接给结论

## 桌面组件与系统入口

- **桌面小部件**：封面 / 歌名 / 歌手三块区域**分别直达**播放页 / 曲库 / 歌单，配「上一首 / 播放暂停 / 下一首」三键
- **下拉快捷磁贴**：三颗 —— 「播放·暂停」（显示当前歌名与歌手）、「下一首」与 **「收藏」**（切换当前曲收藏态，与播放页红心同一套；无当前曲或无法识别身份时置灰）；没有队列时点播放磁贴会直接进应用开始播放，而不是静默失败。详见[设计 · 磁贴收藏](设计-磁贴收藏.html)
- **启动器图标长按快捷方式**：播放全部 / 随机播放 / 我的收藏；冷启动时曲库还在异步装载，所以这三个动作是「先记下意图 → 曲库就绪后再执行」，不会点了没反应
- **车载（Android Auto / 车机自带面板）媒体卡**：车机能识别本应用并提供播放控制，**并可按歌单层级浏览**——
  根目录下是「我的收藏 / 最近播放 / 最近添加 / 最常播放」＋每个自建歌单，点进去看曲目，也可以整单播放
  （浏览树只做歌单这一层，不含专辑 / 歌手 / 文件夹与车机侧搜索）。
- **可被车机列为「默认音乐」（2026-10-27）**：补齐了系统识别「音乐播放器」的三条依据 ——
  `CATEGORY_APP_MUSIC`（启动器音乐分类）、`ACTION_VIEW` + 音频类型（文件管理器「用什么打开」）、
  `MEDIA_BUTTON`（方控 / 蓝牙耳机按键）；并声明了 `MEDIA_PLAY_FROM_SEARCH`（系统语音点歌）。
  **是否被设为默认音乐由车机设置决定，应用无法自己完成**；能否出现在列表里取决于车机厂商用哪条依据，
  诊断包新增「默认音乐候选资格」一段可逐条自检。
- **外部打开即播**：在文件管理器 / 车机文件浏览器里点一个音频文件选「用听风打开」，
  库里有同一首就播库里那份（带封面 / 歌词 / 收藏状态），没有则按文件元数据现造一首临时曲直接播，
  不需要先把它加进扫描范围。系统语音点歌则按查询词搜曲库并播放命中的第一首（搜不到给一句提示）
- **大屏 / 车机**：统一使用**单栏 + 抽屉导航**（v1.1.14 起取消左右双栏）。宽度 ≥ 840dp 时根布局会额外让出底部 56dp，避开车机自带的固定按钮栏，左下角「设置」与迷你播放条不会再被压住

## 设置页

- **页内搜索（G8，v1.2.33）**：主页顶部搜索框，按标题/分区/关键词过滤六大分区及主要设置项；无匹配空态。详见[功能-设置页搜索](功能-设置页搜索.html)。

库页右上角 `⋮` →「设置」。设置页是**一个主页面 + 六个子页**：主页面只放**六张分类卡**（每张卡带一行实时摘要，如「速度 1.00x · 变调 原调 · 继续上次播放 · 均衡器与音效」），点进去才是这一类下真正能改的开关与滑块——改一个开关不用先滚过六组无关内容。每个页面的滚动位置各记各的，从子页返回不会把你顶回顶部。

**点卡进子页 / 按返回逐级退，都走统一的横向滑行动效**（v1.2.9）：下钻时新页从**右侧**推入、旧页向左退一小段并淡出；返回方向相反。标题只淡入淡出（不横向穿动），整段约 260ms。三层结构（主页 → 分类 → 子项）下这一点很关键——之前是瞬切，屏幕几乎没动，看不出是「进去了」还是「就停在这」。

**每个可调项都带「恢复默认」**：只在当前值偏离出厂默认时，行尾才会出现一个 `↺`，点一下回到默认；值本身就在默认状态时不显示，不会白占位置。
