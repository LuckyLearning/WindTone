# 流派 / 年代浏览（G1）

曲库侧增加 **流派**、**年代** 浏览入口，交互与已有「歌手 / 专辑 / 文件夹」一致：列表聚合 → 点进组内曲目 → 可播该组全部。

## 口径

- 聚合字段：曲目元数据里的 `genre` / `year`（或 date 解析出的年）。
- 无元数据归「未知流派」/「未知年代」；空库或全无字段时列表诚实为空（仍可进视图）。
- 年代默认按年份数字**降序**，「未知年代」垫底；也可按添加时间排。
- 流派默认按名称（拼音首字母）。

## 取舍：不升 Room schema

`SongEntity` **没有** genre / year 列；`MusicDb` 使用 `fallbackToDestructiveMigration()`，升 schema 会清库。

本版做法：

| 层 | 做法 |
|---|---|
| 内存 `Song` | 增加可选 `genre: String?` / `year: Int?`（不入表） |
| 扫描 | MediaStore `YEAR` + API 30+ `GENRE`；MMR `GENRE` / `YEAR`·`DATE` |
| 持久 | Prefs JSON 侧缓存 `genre_year_json`（`GenreYearCache`，同 `music_player_prefs`） |
| 冷启动 | `applyLibrary`：`putFromSongs`（有值时）+ `overlay` 盖回 |

**不**重建数据库。若日后要进 Room，再单独评估 Migration / 接受清库。

## 实现要点

| 符号 | 作用 |
|---|---|
| `GenreYear.kt` | `normalizeGenre` / `parseYear*` / `buildGenreGroups` / `buildYearGroups` / `sortYearGroups` |
| `GenreYearCache` | Prefs JSON 读写与 overlay |
| `LibraryView.GENRE` / `YEAR` | 抽屉与车机导航随 `entries` 自动出现 |
| `LibraryCore.refreshGroups` / `openGroup` | 分组与进组播放列表 |

单测：`GenreYearTest`；抽屉 / 车机标签随枚举扩容已更新。
