# 多碟专辑按 discNumber 分组（G3）

专辑详情（及艺人组内曲目）按 **碟号 → 曲序** 排序；多碟时列表显示「碟 1 / 碟 2 …」分区头。无碟信息时行为与改前一致。

## 口径

- **排序**：有碟信息时 `disc → track → title`；无碟信息时仍 `trackNo → title`。
- **分区**：仅当专辑内存在多个有效碟号，或任一碟号 > 1 时显示分区头；单碟无碟号不显示。
- **无碟号曲目**：在「需要分区」的专辑里并入第 1 碟分组。
- **文案**：`lib_disc_n`（英 `Disc %d` / 中 `碟 %d`）。

## 取舍：不升 Room schema

`SongEntity` **没有** `discNumber` 列；`MusicDb` 使用 `fallbackToDestructiveMigration()`，升 schema 会清库。

本版做法：

| 层 | 做法 |
|---|---|
| 内存 `Song` | 可选 `discNumber: Int?`（不入表） |
| MediaStore | `TRACK` 高 16 位 = 碟、低 16 位 = 曲（Android 惯例）；`trackNo` 仍存原始值，排序/展示走 `effectiveDiscNumber` / `effectiveTrackNumber` |
| MMR（文件夹/深扫） | API 28+ `METADATA_KEY_DISC_NUMBER`；曲序 `CD_TRACK_NUMBER` |
| 持久 | Prefs JSON `disc_number_json`（`DiscNumberCache`，同 `music_player_prefs`）；主要为非 MediaStore 路径冷启动盖回 |
| 冷启动 | MediaStore 曲目可从已落库的 `trackNo` **即时解码**，不依赖缓存 |

**不**重建数据库。

## 实现要点

| 符号 | 作用 |
|---|---|
| `DiscNumber.kt` | `decodeMediaStoreTrack` / `parseDiscNumber` / `sortAlbumSongs` / `shouldShowDiscHeaders` |
| `DiscNumberCache` | Prefs 读写与 overlay |
| `LibraryCore.openGroup` | 专辑 / 艺人 / 合辑艺人组内排序 |
| `GroupDetail` | 多碟时分区头（`item` 插入「碟 N」） |
| `MusicRepository.sort` | `ALBUM` / `ARTIST` 排序同样 disc → track |

单测：`DiscNumberTest`。
