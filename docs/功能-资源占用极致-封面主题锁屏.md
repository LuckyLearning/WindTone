# 资源占用极致 · 封面 / 动态主题 / 锁屏 SYNOPSIS

**前提**：车机主路径 = **歌词悬浮窗常开**。本批只砍「窗以外」大头与锁屏路径无意义 Binder，**不**放慢悬浮窗跟词 ticker，不做 SoftEq / LoadControl / 交叉淡入。

## 改动

| 编号 | 项 | 行为 |
| --- | --- | --- |
| **A1** | 封面内存预算 | 位图 `maxMemory/16`、夹 **4~16MB**（原 /8、8~32）；原始字节 `/48`、夹 **1~2MB**（原 /32、1.5~3） |
| **A7** | 通知封面边长 | `NOTIFICATION_COVER_PX` **512→256**（对齐系统大图标） |
| **A5** | 动态主题默认 | `SettingsDefaults.DYNAMIC_THEME = false`；老用户已写入的 prefs 不变，仅新装/重置生效 |
| **A4** | 锁屏/通知 SYNOPSIS | `LockScreenLyricPublisher`：文案去重 + **句内时间窗**内跳过 resolver/`replaceMediaItem` |

## 性能

- 零新增常驻采样线程。
- 锁屏路径：同句 500ms ticker 不再反复解析歌词、不再打 MediaSession Binder。
- 悬浮窗路径未改（仍走 `OverlayTickHelper`）。

## 验证

- 单测：`CoverCacheTest` 预算断言；`LockScreenLyricPublisherHoldTest` 时间窗；`SettingsDefaultsTest`（dynamicTheme=false）。
- 本机构建：`assembleDebug` / 相关 test。
- 真机：装包后导出诊断对比封面 LRU 上限；通知栏封面仍清晰即可；换句 SYNOPSIS 仍切换。
