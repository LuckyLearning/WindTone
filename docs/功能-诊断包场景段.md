# 诊断包 `[场景]` 段（#12）

导出「诊断包（完整）」时追加场景化只读摘要，方便回传后判断冷启动重套 / stash / 手改离开。

## 内容

- **当前**：Prefs.sceneId 与内存 `SceneMode.activeId`（不一致会标明）
- **冷启动计划**：`SceneProfiles.planColdStart` 三态文案
- **Prefs**：`sceneId` / `sceneStash` 有无与可解码；快照摘要（EQ 开关、preset、bands **长度**、增强、scheme、speed、pitch、sleep 剩余）
- **最近切换**：本进程 `DiagLog` 中 `[SCENE]` 行（最多 20 条）

不含凭据与密钥；不打印完整 EQ 曲线数值。

## 实现

- `diag/SceneProbe.kt` → `DiagnosticsReport.Facts.sceneBlock`
- `SceneMode` 在套用 / 退出 / 冷启动 / 手改离开时 `DiagLog.log("SCENE", …)`

代码已随 **≥ v1.2.37** 出包。
