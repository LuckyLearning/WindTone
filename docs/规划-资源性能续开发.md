## 0. 铁律（置顶 · 违反即停）

1. **资源占用与性能 > 功能完备度**。默认轻量、可关；忌长稳 **内存 / 线程 / fd** 膨胀；忌为「功能完整」加常驻采样、双缓冲、大缓存。
2. **车机核心场景 = 歌词悬浮窗常开**。一切优化**不得**牺牲：跟词准时、显隐稳定、侧钮可用、前台包名防抖（`avc` 等）。有窗时**不要**停前台探测 / 盲目放慢跟词 ticker。
3. **SoftEq 滤波核 / 门控勿随意改**。E6 仅上车听感 A/B（[`真机验证清单`](真机验证清单.md) R-03～R-05）；本机勿改双二阶公式、勿改 `SoftEqGate` 决策语义。
4. **交叉淡入（旧 C4）禁止当作优化项**——重叠期双解码/双缓冲，反资源；已有顺序淡入淡出即可。
5. **发版不跑单测**（`release.sh` 默认跳过 `testDebugUnitTest`）。功能合入本机跑相关单测 + `assembleDebug`；改动落本地 **main**；GitHub 用 **`.github-token`**，禁止弹窗要账号。
6. **不做**：为过 Auto-review / CI 而绕路；编译期无依据地剔 SoftEq；暂停久乱摘 WakeMode / 停 FGS（窗常开要稳播）。

## 2. 1.2.44 宋 L 诊断结论（对照基线）

样本：宋 L / DiLink · **v1.2.44** 诊断包（用户附件）。**1.2.45** 主要修跳过计数口径，内存结构预期同族。

| 观察 | 数值 / 现象 | 解读 |
| --- | --- | --- |
| VmRSS | ~**447MB**（峰 ~**555**） | 相对更早 ~600 / 峰 758 **下降一截**；极致序列方向有效 |
| `libc malloc` | ~**132MB**，单段近 **80MB** | **大头 = 解码/播放缓冲**，不是封面 |
| 封面常驻 | ~**1MB** 量级 | **封面非 RSS 大头**；继续狂砍封面 ROI 低 |
| SoftEq | 关；本地 FLAC | 欠载 **0**；B1/拆链方向正常 |
| fd / 线程 | fd ~295 / 32768；线程 ~54 | 无泄漏红灯 |
| 可见性 | 重算/变化 ~**27/26** | 主因隐藏名单 `com.byd.avc` 等与地图来回切——**车机常态**，非空转刷窗 |
| 刷字 / 跳过 | **642 / 0**（1.2.44） | **计数漏记**（同句已在 Bus/paint 层拦住）；非 ticker 狂刷。**1.2.45 已修**，上车应见 **跳过 ≫ 刷字** |
| 封面位图命中 | 0/19 量级 | 曲库小+少滚可出现；原始/磁盘约三成——可后再抠缓存键，非 P0 |
| 平均 CPU | ~12.7%（含深睡分母） | 悬浮窗常开下不离谱；若**静置长播仍长期偏高**再查空转 |
| 冷启动首帧 | ~12s 量级（`activity:onCreate` 大） | **体验项**，非长稳 RSS；勿与长稳优化混为一谈 |
| 电池白名单 | 未进 | 一般不直接抬 RSS；后台偶发卡顿可建议用户加 |

**给下一 AI 的一句话**：下一刀优先 **播放缓冲 / 静置 CPU / 大库堆副本**，不要再把封面当主战场；悬浮窗只做「同功能更省」，不砍能力。

## 3. 禁止项与勿重复项

### 3.1 禁止

| 禁止 | 原因 |
| --- | --- |
| 交叉淡入当「优化」 | 双解码/双缓冲，反资源 |
| 改 SoftEq 滤波公式 / 门控语义 | E6 仅上车；核已冻结待听感 |
| 有窗时停前台包名探测 / 无障碍看护 | 显隐会坏 |
| 有窗时盲目把跟词 ticker 500ms→2s | 伤准时；只允许「字不变不重绘」类 |
| 暂停停 FGS / 乱摘 WakeMode | 窗挂着要稳播、易被杀 |
| 全局砍远程 LoadControl 当默认 | 弱网/网盘易卡（本地已分场景） |
| 新增常驻采样线程「盯资源」 | 自身反资源；诊断仅导出时取数 |
| 发版时本地强跑全量单测 | 规则：发版不跑单测 |
| 无 token 弹窗登录 GitHub | 用 `.github-token` + `push.sh` / `release.sh` |

### 3.2 勿重复（已做）

- A1/A7/A5/A4、B1 分场景 LoadControl、A6/B2/B3 关路径拆链、A3/A11 默认、字不变不重绘、跳过计数三路、1.2.42 RGB_565/可见性降频、1.2.43 包名防抖、Prefs 元数据裁剪、通知/widget 565+降采样、proc `fdLimit`/`proc_key`。

### 5.2 何时停

- 用户未提供新诊断 / 未喊继续时：**停写码**，只答疑。  
- 静置长播 VmRSS、欠载、跳过比已达标，再抠封面或交叉淡入冲动：**停**。  
- SoftEq / 交叉淡入 / 停 FGS 提案：**拒**。  
- Actions 额度不足：**只 push main，不打 v\* tag**（见 AI 指南 §0.3）。

### 5.3 何时再发版

- 用户明确说「发版」才 `bash scripts/release.sh …`（发版**不**跑单测）。  
- 建议攒：**至少一项用户可感知的资源项** + 诊断可对照字段，再出包。  
- 仅文档/单测口径：可只推 main，等用户要包再发。

### 5.4 本机每项交付套路（给 AI）

1. 读本文件 + 对应旧 `功能-*.md`，确认未重复。  
2. 改代码；**相关** JVM 单测 + `assembleDebug`。  
3. 写/更新 `docs/功能-资源占用极致-….md`（短、可验收）。  
4. `git add` 相关文件 → commit 信息前缀 `perf:` / `fix(overlay):` / `docs:`。  
5. `bash scripts/push.sh` 推 **main**。  
6. **不**擅自改 `appVersionName` / 打 tag，除非用户要发版。
