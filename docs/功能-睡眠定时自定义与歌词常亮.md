# 睡眠定时自定义分钟 + 看歌词常亮（G5 / G6）

> 落地日：2026-10-31（Asia/Shanghai）
> 版本：随下一 patch 发版（实现提交在前，versionCode 由 `scripts/release.sh` 抬）

## 干了什么

### G5 睡眠定时：自定义分钟

睡眠定时 Sheet 在 15 / 30 / 60 / 90 预设之外，新增 **「自定义分钟」** 输入框：

- 只接受数字，最长 4 位；合法范围 **1～720**（12 小时）
- 点「确定」后走既有 `onSet(minutes)` → `PlayerActions.sleepAfter` → `SleepTimer.start`
- 非法输入只标红提示，不关 Sheet、不改当前定时
- 纯函数 `SleepTimer.clampCustomMinutes` 钉住上下界，单测覆盖 0 / 负 / 正常 / 超大

其它档（播完当前曲 / 专辑 / 队列、取消、10 秒淡出）不动。

### G6 看歌词常亮

播放页处于 **歌词态**（`showLyrics == true`）时，根 `Box` 挂 `LocalView.current.keepScreenOn`；切回封面态自动取消。不新增设置开关（快赢：看歌词就常亮）。

## 怎么干的

1. `SleepTimer.clampCustomMinutes(raw)`：`coerceIn(1, 720)`。
2. `SheetsPlayback.SleepSheet`：Composable 顶层记住输入态；预设列表下加 `OutlinedTextField` +「确定」。**未改** `QueueSheet`（避开 A3/A4 队列抽屉并行）。
3. `PlayerScreen` 根 `Box`：`Modifier.fillMaxSize().then(if (showLyrics) LocalView.current.keepScreenOn else Modifier)`。
4. `SleepTimerTest` 增补夹取用例。
5. 文档：本文件 + `功能说明.md` 睡眠定时一行补「自定义分钟」；歌词相关补常亮一句。

## 怎么验

1. 播放页 → 播放设置 → 睡眠定时 → 自定义填 `45` → 确定 → 剩余约 45:00。
2. 填 `0` / 空 / `9999` → 标红，不关 Sheet；`9999` 若绕过 UI 也应被 clamp 成 720（引擎路径经 UI 已挡）。
3. 切到歌词态：屏幕应保持常亮（可对照系统自动锁屏时间）；切回封面后应恢复可灭屏。
4. `./gradlew :app:testDebugUnitTest --tests com.luckylearning.windtone.playback.SleepTimerTest`
