# 侧钮上下顺序设置（A1 / 补齐 B1 UI）

> 落地日：2026-10-31（Asia/Shanghai）  
> 版本：v1.2.18（v1.2.17 发版时本提交尚未合入 main，功能随本版出）

> **2026-10-31 增补**：第四颗侧钮「无障碍状态」合入后，默认顺序为 `collapse,play_pause,player,a11y`；顺序 UI 自动列出四颗。详见 [功能 · 悬浮窗侧钮 · 无障碍状态](功能-侧钮无障碍状态.md)。

## 干了什么

设置 → 悬浮歌词：在「显示悬浮窗侧钮」且整体开启时，于三颗单颗显隐开关下方新增 **「侧钮上下顺序」** 列表。

- 按当前顺序列出三颗钮（收起 / 播放暂停 / 打开播放页）
- 每行 **上移 / 下移**（`IconButton` + 箭头），点一下即写回 Prefs CSV
- 非默认顺序时出现 **「恢复默认顺序」**
- 默认仍是 `collapse,play_pause,player`（与改前写死顺序一致）

## 怎么干的

1. **盘点**：`Prefs.overlayHandleOrder`、`OverlayCollapseHelper.mergeHandleOrder` / `handleOrderCsv` / `visibleHandles`、`LyricOverlayService` 按序挂载、`SettingsRepository.setOverlayHandleOrder`、`PlayerUiState.overlayHandleOrder`、`onOverlayHandleOrder` 接线 **早已齐**（B1，`44b6786`）。设置页却只加了回调参数与 `KeyboardArrow*` import，**没有画出控件**——规划勾了「B1 已落地」，用户实际调不了顺序。
2. **UI**：在 `SettingsOverlayPage` 的 `if (player.overlayHandles)` 块内、三颗 `SwitchRow` 之后插入顺序列表；交互对齐「分类顺序」页（`SettingsMenuOrderPage`）的上移/下移，车机大触控友好；三颗固定项不引入 `LazyColumn` 长按拖，避免与设置页滚动冲突。
3. **写盘路径**：`onOverlayHandleOrder(csv)` → `PlaybackEngine` / `OverlaySettings` → `SettingsRepository.setOverlayHandleOrder`（内部再 `mergeHandleOrder` 纠偏）→ Prefs → 悬浮窗服务读 CSV 重建侧钮列。
4. **单测**：`OverlayCollapseHelperTest` 增补「上移下移等价于 CSV 重排并可 roundtrip」。

## 怎么验

1. 车载模式 + 悬浮歌词开 + 侧钮开。
2. 设置 → 悬浮歌词 → 「侧钮上下顺序」把「打开播放页」上移到最上。
3. 回桌面看左侧三颗钮：最上应是音符（打开播放页），顺序与设置一致。
4. 杀进程重开：顺序仍在。
5. 点「恢复默认顺序」：回到 收起 → 播放暂停 → 打开播放页。

## 不做什么

- 不改掩码 / 挂载引擎
- 不做长按拖拽把手（与「分类顺序」一致用按钮）；第四颗「无障碍」见独立功能文
