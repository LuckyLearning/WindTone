# 无障碍开机被关（宋 L DM-i / DiLink）

> 适用：比亚迪宋 L DM-i（含 **2026 款 / DiLink 100**）及同类 DiLink 车机。  
> 相关代码：`AccessibilityWatchdog`、`ForegroundAppService`、`CarBootReceiver`、设置 → 关于与诊断 → 前台应用记录。

## 根因（不是 App 偏好丢了）

DiLink 重启后会清掉（或无法拉起）第三方应用的无障碍服务，表现为
`Settings.Secure.ENABLED_ACCESSIBILITY_SERVICES` 里不再包含听风。

- **不是**听风自己的 Prefs / 场景切换清开关。
- 普通应用**不能**静默写回该项（需 `WRITE_SECURE_SETTINGS`，signature 级）。
- 2026 款起车厂收紧 ADB 扫码后，多数车主也拿不到 `pm grant` 这条捷径。

因此「永远不被关」在系统侧做不到；应用侧只能：**发现掉线 → 一次点击回到开启页**，并推荐更稳的备胎通道。

## 听风已经做的

1. 服务真正连上时记住「这台机开过」（`seen_on`）。
2. 开机广播 / 冷启动 / 回到前台：`AccessibilityWatchdog.checkAndNotify`。
3. 若曾用 adb 授予 `WRITE_SECURE_SETTINGS`：尝试自动写回（合并进现有列表，不覆盖其它服务）。
4. 否则发通知；诊断页置顶「去开启」；播放页可显示前台识别状态钮。
5. **使用情况访问**（UsageStats）是独立通道，DiLink 一般不会像抹无障碍那样清掉，延迟约 1.5 秒。

## 用户怎么钉住（最短步骤）

### A. 推荐：双通道（稳）

1. 听风 → 设置 → 关于与诊断（关于卡连点 5 次解锁调试区，若需要）→ **前台应用记录**。
2. 打开 **使用情况访问 / 使用情况权限**（点按钮跳转，授权听风）。
3. 再打开 **无障碍**（车辆设置 → 系统设置 → 无障碍 → 已下载的服务 → 听风）。
4. 应用管理 → 听风 → **允许自启动 / 允许后台活动**（有则开）。
5. 同一页或耗电管理 → **不受限制 / 允许后台**（电池白名单）。

之后：无障碍偶发被开机清掉时，通知点一下即可；**使用情况访问仍在**，「按应用隐藏」不会整晚失效。

### B. 每次开机只修无障碍

1. 开机后若出现「辅助功能被系统关闭了」通知 → 点开 → 打开听风。
2. 或听风内：设置 → 前台应用记录 → 「去开启」/ 无障碍设置。
3. DiLink 路径优先：**车辆设置 → 系统设置 → 无障碍**。

### C. 开发机可选（多数 2026 车机不可用）

```text
adb shell pm grant com.luckylearning.windtone android.permission.WRITE_SECURE_SETTINGS
```

授予后，听风开机可尝试自动写回无障碍；未授予时行为与以前一样（通知一键恢复）。

## 验证

- 开无障碍 → 重启车机 → 应收到恢复通知（或诊断页红条）→ 一点即回开启页。
- 仅开使用情况访问 → 进名单内应用（如 360）约 2 秒内悬浮窗应收起。
