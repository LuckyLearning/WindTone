# 资源占用极致 · 关路径拆链（A6 / B2 / B3）

**前提**：车机主路径 = 歌词悬浮窗常开。本批只卸未启用音效，**不**改 SoftEq 双二阶滤波公式/核、不碰悬浮窗跟词、不做交叉淡入。

## 改动

| 编号 | 项 | 行为 |
| --- | --- | --- |
| **A6** | 硬 EQ | `eqEnabled=false` / 绑定后仍关闭 → **`releaseEffects()`** 拆掉 Equalizer/BassBoost/Virtualizer/Loudness/Reverb；再开时按会话 `attach` 重建。A/B 旁路（`setBypassed`）不拆。 |
| **B2** | SoftEq | 关闭或曲线近似平直 → `SoftEqAudioProcessor.isActive=false`，Media3 跳过；**仍注册**在 sink 上以免开时重建 AudioSink 爆音。滤波核未改。 |
| **B3** | StereoBalance | `balance==0` → 自研 `StereoBalanceAudioProcessor.isActive=false`（取代恒等 ChannelMixing）；偏左/右才进链。 |

入口清单：`PlaybackAudioProcessors.forAudioSink()`。

## 性能

- 硬 EQ 关：无会话 AudioEffect 常驻。
- SoftEq / 平衡默认关或居中：处理链上无 PCM 乘法。
- 不重建 ExoPlayer；开关靠 isActive / attach-release。

## 验证

- 单测：`SoftEqAudioProcessorActiveTest`、`StereoBalanceAudioProcessorTest`、既有 SoftEq / StereoBalance 纯函数测。
- 本机：`assembleDebug` + 上述单测。
- 真机：关 EQ 看 effect 实例；开 SoftEq / 拖平衡听有无爆音。
