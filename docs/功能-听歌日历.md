# 听歌日历（H7）

按日热力月历：色块深浅表示当日收听时长，点选某天查看摘要。

## 入口

收听报告页顶栏跨度切换旁的 **「听歌日历」**；也可从同一报告栈返回后再进。

## 数据

- **唯一数据源**：既有 `listen_log` 小时桶（[ListenLogEntity]），与收听报告日曲线同一口径。
- **聚合**：`buildListenCalendarMonth`（[ListeningReport.kt]）按**本地午夜**划日、周一开头补齐邻月灰格。
- **不新建统计管线**、不写新表、不上传。

## 行为

| 项 | 说明 |
|---|---|
| 月切换 | 左右翻月；不可翻到「当前月」之后 |
| 色块 | 相对本月单日峰值归一化；无收听为浅底纹 |
| 点选 | 下方摘要：日期（含周几）+ 当日收听时长 |
| 概览 | 本月合计 / 有听的日子 / 单日最多 |

## 测试

`ListenCalendarTest`：周一起始与前导格、邻月桶不计入本月、空月、文案格式。

## 版本

随 v1.2.31（或当时下一空闲版号）发版；**不重建数据库**。
