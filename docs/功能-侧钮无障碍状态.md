# 悬浮窗侧钮 · 无障碍状态

> 落地日：2026-10-31（Asia/Shanghai）  
> 合入：main；**发版**：**v1.2.38**（详见 [`版本历史.md`](版本历史.md)）

## 干了什么

把播放页「前台识别 / 无障碍」的**状态色 + 打开系统页**做成悬浮窗**第四颗侧钮**，与收起 / 播放暂停 / 打开播放页同列：

- **绿图标** = 听风无障碍服务已开；**红图标** = 未开
- **点按** → `ForegroundAppDetector.openAccessibilitySettings`（与播放页同一通道）；**不能**在应用内假开关
- 设置 → 悬浮歌词：新增「显示无障碍状态」开关（kind=3）；顺序 CSV 默认末尾追加 `a11y`；旧安装缺项由 `mergeHandleOrder` 自动补齐
- 侧钮挂载期间约 2s 轮询刷新颜色（用户从系统页返回后也能跟上）

## 怎么干的

1. `OverlayCollapseHelper`：`OverlayHandleKind.A11Y`（bit3=8，kind=3）；`handleMask(..., a11y)`；默认顺序 `...,a11y`
2. Prefs / UiState / SettingsRepository / OverlaySettings：`overlayHandleA11y`（默认开）
3. 新 `AccessibilityIconView`（自绘无障碍人形，对齐现有侧钮圆底）
4. `LyricOverlayService`：`attachA11yHandle` / detach / 位置列 / 显隐；点击 Toast 复用 `player_a11y_open_failed` / `player_a11y_no_page`
5. `SettingsOverlayPage`：第四颗 SwitchRow + 顺序标题；i18n `oh_show_a11y*` / `oh_name_a11y`（en+zh）
6. 单测：`OverlayCollapseHelperTest` 掩码 15、默认 CSV、merge 补 `a11y`、可见筛

## 怎么验

1. 车载模式 + 悬浮歌词 + 侧钮开；设置里确认「显示无障碍状态」开。
2. 无障碍关：侧栏最下（默认）红钮；点一下跳系统无障碍页。
3. 开启听风无障碍后回桌面：约 2s 内变绿（或切一下前台触发刷新）。
4. 关掉该单颗开关：钮消失，其它侧钮不受影响。
5. 顺序里把「无障碍」上移：屏幕竖直顺序一致。

## 2026-10-31 补：三档显示（按状态自动隐藏）

用户诉求：这颗钮「无障碍关闭时显示、无障碍开启时隐藏」。

设置里原来的单颗开关（开 / 关）升级成**三档**：

| 档位 | 值 | 无障碍在跑 | 无障碍未跑 |
| --- | --- | --- | --- |
| 常显（默认） | 2 | 绿钮 | 红钮 |
| 仅未开启时显示 | 1 | 不显示 | 红钮 |
| 不显示 | 0 | 不显示 | 不显示 |

三条实现口径：

1. **判据是「真的在跑」**：`A11yRuntime.running()` = 系统里勾着 **且** `ForegroundAppService` 当前已连接。
   只看勾选会在 DiLink 掉线（勾还在、服务已死）时把入口藏掉 —— 那正是最需要它的时候。
   颜色也统一用这个口径：绿 = 真的在工作。
2. **轮询不跟着这颗钮生灭**：`startA11yWatch()` 从「挂钮时启动」升级成「侧钮状态轮询」，
   即使无障碍钮已被摘掉也照跑；发现掩码变了就 `syncHandlesVisibility()` 整组重建。
   只有「一颗钮都不该显示」（mask == 0）时才停。
3. **顺序列表里标注**：三档把钮藏起来时，顺序设置里那一行下面会多一行「（当前已隐藏）」——
   顺序仍占位（否则没法调序），但用户不会以为设置没生效。

迁移：旧布尔 `overlay_handle_a11y`（true/false）在读取时换算成 2/0，**不写回、不删除**。
