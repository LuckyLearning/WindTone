# 左右声道平衡（#9）

在「均衡器与音效」弹层的 **播放过渡** 区增加 **左右声道平衡** 滑条：偏左 / 居中 / 偏右。

## 入口

均衡器与音效 → **播放过渡** →「左右声道平衡」。

- 取值 **-100…+100**（0 = 居中）。旁注显示「居中 / 偏左 n / 偏右 n」。
- Prefs 键 `stereo_balance`，杀进程后保留。

## 与「音量平衡」的区别

| | 左右声道平衡（本功能） | 音量平衡（曲间响度） |
|---|---|---|
| 作用 | 同一首歌的 L/R 听感偏向 | 不同歌曲之间的整体响度对齐 |
| 实现 | Media3 `ChannelMixingAudioProcessor` | `player.volume` × ReplayGain / RMS |
| 依赖 AudioEffect | **否** | **否** |

## 车机 / 效果器不可用

与淡入淡出、音量平衡相同：不走 `Equalizer` / `BassBoost` 等 AudioEffect。  
当本机报 `DEVICE_REJECTED` 时，文案写明这三项仍可用，并放在「仍然可用」框内。

## 实现要点

| 符号 | 作用 |
|---|---|
| `StereoBalance` | 纯函数：增益、混音系数、文案 |
| `StereoBalanceFx` | Prefs ↔ 单例 `ChannelMixingAudioProcessor` |
| `PlaybackService` | `DefaultRenderersFactory.buildAudioSink` 挂 processor |
| `EqSheet.PlaybackTransitionSection` | 滑条 UI |

增益算法：保留较响一侧为 1.0，对侧线性衰减（全左时右=0，全右时左=0）。

单测：`StereoBalanceTest`；不可用文案：`EqUnavailableCopyTest`。
