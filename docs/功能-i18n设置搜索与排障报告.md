# i18n 设置搜索词 + 排障报告正文（第 23 批）

把 **SettingsSearchCatalog** 关键词表，以及 **ForegroundProbe** 前台识别排障报告正文，收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–22 批同一套约定。详见 `docs/AI开发指南.md` § i18n 第 23 批。

## 覆盖范围

### `ss_kw_*`（设置搜索关键词）

- 每条 `SettingsSearchEntry.keywordsRes` 指向双语 token 串
- **中英同串**写在 values 与 values-zh（不是「翻译」）：英文 ROM 也能用「车载 / 悬浮 / 片头」命中
- `SettingsSearch.filter` 经 `resolve` 取关键词

### `fp_*`（ForegroundProbe 排障报告）

- 标题 / 分段 / 结论 / 推荐路径 / 候选标签 / yes-no
- `collect()` 写入 Candidate 的用户可见 label 同步走资源
- 启动器应用名匹配仍含字面「设置」（系统 launcher 标签，非本批文案）

## 刻意不改

- SoftEq / 播放内核行为
- `DiagnosticsReport` 诊断包外壳与其它 Probe 段（下一批候选）

## 验证

- `./gradlew :app:compileDebugKotlin --offline`
- `SettingsSearchTest`、`ForegroundProbeTest`（Robolectric `zh-rCN` + `AppStrings.init`）
