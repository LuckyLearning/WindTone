# 场景化模式（驾车 / 通勤 / 助眠）

**状态**：已落地（`57cd008` + `c49abd9`，随本版发版）  
**日期**：2026-10-31

## 干了什么

把已有的「音效方案 / 均衡器 / 变速变调 / 睡眠定时」收成**一键情境档**，而不是再做一个调音台。
场景 = 情境组合层；音效方案仍只管听感。MVP **不做**自定义场景编辑器、不做 10+ 档、不绑歌单（`playlistId` 预留）。

## 入口

| 位置 | 行为 |
| --- | --- |
| **播放设置**抽屉 →「场景」分区 | 手机 / 车机通用；`SceneChipsRow`，带一句提示 |
| **车机播放页**控制区上方 | 仅车载模式非沉浸态；大触控芯片（约 56dp），不显示提示 |

芯片：驾车 / 通勤 / 助眠 / 关闭。点当前已选档 = 关闭并还原；点「关闭」同理。

## 三档行为（`SceneProfiles`，id 持久化后不可改）

| id | 名称 | 听感来源 | 睡眠 | 速度 | 变调 |
| --- | --- | --- | --- | --- | --- |
| `drive` | 驾车 | 音效方案「车载驾驶」 | 取消（0） | 1.0x | 0 |
| `commute` | 通勤 | 音效方案「清澈人声」 | 取消（0） | 1.0x | 0 |
| `sleep` | 助眠 | 音效方案「沉浸环绕」 | **45 分钟** | 1.0x | 0 |

`null` 字段 = 不碰该项；`sleepMinutes=0` = 明确取消睡眠定时。

## Stash 语义（`SceneStash`）

- **进第一档前**拍整包快照：EQ 开闭 / 预设 / 频段 / 增强 / 混响 / 当前方案 id、速度、变调、当时睡眠剩余毫秒。
- **档与档之间切换不重拍**（沿用进场景前那份基线）。
- **退出**（关芯片 / 再点当前档）按 stash 还原听感 + 速度 + 变调 + 睡眠；坏格式按「无快照」处理，保住现状。
- **手改 EQ / 另选方案**（`SceneMode.onManualEqEdit`）：离开场景并**丢弃** stash —— 当前值成为新常态（与离开音效方案同一口径）。场景套用中的写入不会误触发清档。

编码：`v1` + 11 字段，单元分隔符，纯 JVM 可测，无 JSON。

## 冷启动恢复（`restoreOnColdStart`）

杀进程再开：

1. `sceneId` 空 → 无场景。
2. `sceneId` 仍是内置档 → **按档重套听感**，**不重拍** stash（避免把「已是场景听感」写成退出基线；退出仍还原到进场景前）。
3. 未知 id → 清标记；若仍有 stash 则走 `exit()` 还原。

必须在 `PlaybackEngine` 挂上 `SceneMode.Hooks`（变速 / 变调 / 睡眠）之后调用。

## 怎么干的（实现笔记）

| 文件 | 职责 |
| --- | --- |
| `playback/SceneProfiles.kt` | 三档数据 + 选择 / 冷启动纯函数 |
| `playback/SceneStash.kt` | 快照编解码 |
| `playback/SceneMode.kt` | 编排：apply / exit / 手改离开 / 冷启动 |
| `ui/SceneChips.kt` | 芯片 UI |
| `PlaybackEngine` | `init` + `setHooks` + `restoreOnColdStart` |
| `AudioFx` | 手改时回调 `onManualEqEdit` |
| 单测 | `SceneProfilesTest` / `SceneStashTest`（含 chips / 选择 / 冷启动） |

Prefs：`sceneId`、`sceneStash`（默认空）。
