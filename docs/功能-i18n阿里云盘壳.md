# i18n 阿里云盘壳（第 19 批）

把 **Aliyun 登录壳**里仍硬编码的用户可见文案收进既有 i18n 体系。

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1～18 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 19 批。

## 覆盖范围

### 已有（前几批 / 早先合入）

- `AliyunPanPage` / `AliyunPanDialogs` 主体已走 `aliyun_*`（顶栏、菜单、错误、进度、粘贴令牌弹层、保存歌单等）

### 本批前缀 `aqr_*`（AliyunQrLoginDialog）

- 标题 / 按钮：`aqr_title` / `aqr_retry` / `aqr_new_code` / `aqr_close`（取消复用 `cancel`）
- 生成失败兜底：`aqr_gen_failed`
- 失败引导 / 网页令牌：`aqr_fail_hint` / `aqr_web_token`
- 保存中 / 生成中：`aqr_saving` / `aqr_generating` / `aqr_generating_waited` / `aqr_generating_slow`
- 扫码状态：`aqr_status_scanned` / `aqr_status_scan`
- 轮询重试：`aqr_poll_retry` / `aqr_poll_retry_detail`
- 扫码提示 / CD：`aqr_scan_tips` / `aqr_cd_qr`
- 粘贴框字段名：`aliyun_refresh_token_field`

## 刻意未改

- SoftEq / SoftEqSpike / 播放内核
- 云盘协议 / `AliyunAuth` / `AliyunQrLogin` / `AliyunDrive` 逻辑与 API 错误原文（服务端英文/中文 message 仍原样展示）
- versionName / tag / release
- `AliyunPanPage` 已 i18n 的 `aliyun_*` 键（本批只补扫码弹层与字段标签）

## 验证

- `./gradlew :app:compileDebugKotlin --offline`
- `./gradlew :app:testDebugUnitTest --tests com.luckylearning.windtone.ui.AliyunPanPageTest --offline`（若存在）
- 人工扫：`AliyunQrLoginDialog.kt` 用户可见文案无残留中文硬编码（KDoc/注释除外）
