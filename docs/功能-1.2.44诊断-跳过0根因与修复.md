# 1.2.44 诊断：跳过 0 根因与修复

宋 L / DiLink · v1.2.44 诊断包：`刷字 642（跳过 0）`。

## 根因（不是「每 tick 仍 setText」）

1. **同句去重主路径在 `LyricOverlayBus.publish`**：进度 tick 仍解析当前行，但
   `resolved/playing/title/artist` 未变时直接 return，**不叫醒** binder。
2. **binder 另有 `paintKey` 超集指纹**：包名防抖等重入且字未变时，根本不进
   `renderLines`。
3. **`OverlayMetrics.onRenderSkip` 原先只挂在 `renderLines` 的 `OverlayRenderKey`
   二次去重上**。paintKey 已先过滤时该路径几乎不可达 → 诊断恒「跳过 0」。
4. 车上 642 刷字 ≈ 真换行 / 真样式变化次数，**不是** 500ms ticker 狂刷。

封面预算文案仍写 `maxMemory/8` 夹 8~32：仅诊断字符串未跟 A1（实现已是 /16、4~16）。

## 修复（本机，未发版）

| 层 | 改动 |
| --- | --- |
| Bus | 内容未变 early-return 时 `onRenderSkip()` |
| binder | `!paintChanged` 时 `onRenderSkip()`（仍不 compose/setText） |
| renderLines | 抽出 `OverlayRenderDeduper`；同键 `begin`→跳过；单测锁死 |
| 诊断文案 | `mp_budget` 对齐 A1：位图 /16 夹 4~16 · 原始 /48 夹 1~2 |

有意未动：跟词节拍、前台探测、SoftEq 核、发版。

## 车上怎么验（需再发版）

装含本修复的包 → 开悬浮窗长播 → 诊断应见 **跳过 ≫ 刷字**；主观跟词不糊、不滞后。
