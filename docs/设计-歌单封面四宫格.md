# 设计 · 歌单封面四宫格

> 版本：**v1.2.16** · 日期：2026-10-31 · 状态：已落地

## 干了什么

歌单列表每一行左侧的封面，从「只显示第一首」改成：

| 歌单内歌曲数 | 封面区表现 |
| --- | --- |
| 0 | 占位图标（`QueueMusic` + primaryContainer） |
| 1 | 整图一张（与改前一致） |
| 2～4+ | **2×2 拼图**：按歌单顺序取前 4 首；不足 4 格的位置留空底色 |

自建歌单与三个虚拟歌单（最近播放 / 最常播放 / 我的收藏）走同一规则。

## 怎么干的

### 数据

- `PlaylistInfo.coverSong: Song?` → `coverSongs: List<Song>`（最多 4 首），并保留只读属性 `coverSong` = `coverSongs.firstOrNull()`，旧调用不破。
- 纯函数 `playlistCoverSongs(songs, limit=4)`：截前 N 首。
- 枚举 `PlaylistCoverMode { ICON, SINGLE, GRID }` + `playlistCoverMode(count)`：把「几首歌 → 哪种布局」集中一处，单测可钉死。

填充点：

- 自建：`PlaylistStore` 读出歌单曲目后 `playlistCoverSongs(songs)`。
- 虚拟：`virtualPlaylistInfo` 对 `extraFavorites` / `extraRecent` / `extraMostPlayed` 同样调用。

### UI

- 新增 `ui/PlaylistCoverArt.kt`：按 mode 画 ICON / SINGLE / GRID。
- GRID：外框 `clip(RoundedCornerShape)`，内 2×2；格间距 1dp；有歌的格子走现有 `CoverArt`（→ `CoverRepository`），空格 `surfaceContainerHighest`。
- `LibraryLists.PlaylistRowPlay` 统一 `PlaylistCoverArt(info.coverSongs)`。

### 测试

- `PlaylistCoverTest`：截取上限与顺序；mode 随 count 降级。
- `VirtualPlaylistInfoTest`：补 `coverSongs` 断言 +「多于 4 首只取前 4」。

### 刻意不做

- 不另开封面解码 / 缓存路径（格内仍 `CoverArt`）。
- 不做「用户自选歌单封面图」。
- 不重建数据库；`coverSongs` 是内存派生，不落盘。

## 验证

- 单测：`PlaylistCoverTest` + `VirtualPlaylistInfoTest`。
- 与场景化模式同发 **v1.2.16**。
