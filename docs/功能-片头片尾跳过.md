# 片头 / 片尾固定秒跳过（H2）

## 做什么

在**设置 → 播放 → 播放行为**里为每首歌配置：

| 项 | 行为 | 范围 |
|---|---|---|
| **跳过片头** | 开播后自动 seek 到 N 秒 | 0～120 秒；**0 = 关闭** |
| **跳过片尾** | 距结束 ≤ M 秒时切下一首 | 0～120 秒；**0 = 关闭** |

切歌策略与现有一致：走 `MediaController.seekToNextMediaItem()`（列表循环 / 单曲 / 停播由当前播放模式决定）。

## 与「跳过静音」的区别

| | **跳过片头/片尾（H2）** | **跳过静音** |
|---|---|---|
| 判据 | **固定秒数**（用户设定） | ExoPlayer 静音检测 |
| 作用点 | 开播 seek；近结尾切歌 | 解码时跳过静音采样 |
| 适用 | 有固定广告/口播片头尾的曲库 | 整轨、现场录音开头空白 |
| 默认 | 均关闭（0 秒） | 关闭 |

两者可同时开：先按固定秒跳片头，静音检测仍按其自身逻辑工作。

## 边界

- 整曲时长 ≤ 片头 + 1 秒：不自动 seek（避免听不到内容）。
- 整曲时长 ≤ 片尾：不触发片尾跳过（避免一开播就切）。
- 用户已手动拖过片头窗口：本曲不再拉回。
- 每曲片头 / 片尾各最多触发一次（切歌后重置）。

## 实现要点

- 纯函数：`playback/IntroOutroSkip.kt`（可单测）。
- Prefs：`skip_intro_seconds` / `skip_outro_seconds`（SP + DataStore 双写）。
- 引擎：`onMediaItemTransition` / `STATE_READY` 片头；进度 ticker 片尾。
