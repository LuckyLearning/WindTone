# 设置页内搜索（G8）

> 落地日：2026-10-31（Asia/Shanghai）
> 版本：随 **v1.2.33** 发版

## 干了什么

设置主页顶部增加搜索框：按**标题 / 分区名 / 关键词**过滤可见设置项，至少覆盖六大分区（外观 / 播放 / 歌词 / 曲库与存储 / 关于与更新 / 实验室）及其主要条目。

- 空查询：仍显示原来的分类卡。
- 有查询：命中项以带右箭头的入口行列出，点进对应子页。
- 无命中：居中空态「没有匹配的设置项」。

## 怎么干的

1. **纯函数** `SettingsSearch.filter` + 静态目录 `SettingsSearchCatalog`（`SettingsSearch.kt`）。
2. **UI** `SettingsRootPage` 顶部 `OutlinedTextField`；即时过滤，不改子页结构。
3. **文案** `set_search_hint` / `set_search_empty` / `set_search_cd`（`values` + `values-zh`）。
4. **单测** `SettingsSearchTest`：空查询、标题、关键词、分区、无命中、六分区覆盖。
5. **文档**：本页 + 功能说明「设置页」一条；发版写入版本历史。

## 怎么验

1. 打开设置：主页顶部应有搜索框。
2. 输入「车载」→ 应出现车载模式（或外观相关）入口；点进外观页。
3. 输入「片头」→ 应出现跳过片头；点进播放页。
4. 输入一串无意义字符 → 空态提示。
5. 清空搜索 → 六张分类卡恢复。
6. `./gradlew :app:testDebugUnitTest --tests com.luckylearning.windtone.ui.SettingsSearchTest`

## 不做什么

- 不在子页内再挂一套搜索，也不做滚动定位到具体滑块。
- 不做拼音 / 历史 / 语音（曲库搜索另有）。
- 不把全部开关动态化成可过滤列表（避免大重构）。
