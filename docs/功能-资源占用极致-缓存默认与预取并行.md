# 资源占用极致 · 缓存默认与预取并行（A3 / A11）

**前提**：车机主路径 = 歌词悬浮窗常开；场景以**本地曲库**为主。本批不动 SoftEq 滤波核、不碰悬浮窗跟词/重绘、不做交叉淡入、不发版。

## 改动

| 编号 | 项 | 行为 |
| --- | --- | --- |
| **A3** | `OnlineMediaCache.MAX_BYTES` | 默认 **512MB → 128MB**。[`LIMIT_STEPS`] 仍为 128/256/512/1024/2048MB。`limitBytes` 用 `getLong(KEY, MAX_BYTES)`：**未写入过 prefs** 的新装/升级拿新默认；**已选过档位**的用户保留现值。UI「默认」徽标跟随 `MAX_BYTES`。 |
| **A11** | 预取 | `SettingsDefaults.ONLINE_CACHE_PREFETCH = false` + Prefs 双写；`PlaybackEngine` ticker 仅在打开时调用 `CachePrefetcher.plan`，关闭时 `cancel()`。候选本就只含 http(s)。 |
| **A11** | 并行分片 | `ONLINE_PARALLEL_DOWNLOAD = false`；`ParallelDownloadRegistry.obtain` 未开设置直接 `null`（走单连接缓存）。`SegmentPlanner.DEFAULT_SEGMENTS` **5→3**（开启后也偏省）。 |
| UI | 在线设置 | `SettingsOnlinePage` 播放缓存区增加两行 `SwitchRow`（可搜）；设置搜索 `ss_kw_*`。 |

## 性能

- 新装默认在线缓存封顶 128MB，少占 `cacheDir`。
- 默认无后台预取协程、无多连接分片探测/写盘；本地为主时几乎零额外成本。
- 需要在线加速时用户可自行打开；并行默认段数更低。

## 验证

- 单测：`OnlineMediaCacheTest`（默认 128 ∈ LIMIT_STEPS）、`SegmentPlannerTest`（3 段）、`SettingsDefaultsTest`（两开关与 Defaults 一致）、既有 `CachePrefetchPolicyTest`。
- 本机：`assembleDebug` + 上述相关测。
- 真机（可选）：纯本地队列无预取/并行网络；打开开关后弱网听在线曲。
