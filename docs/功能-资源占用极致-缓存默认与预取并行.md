# 资源占用极致 · 缓存默认与预取并行（A3 / A11）

**前提**：车机主路径 = 歌词悬浮窗常开；场景以**本地曲库**为主。本批不动 SoftEq 滤波核、不碰悬浮窗跟词/重绘、不做交叉淡入、不发版。

## 改动

| 编号 | 项 | 行为 |
| --- | --- | --- |
| **A3** | `OnlineMediaCache.MAX_BYTES` | 默认 **512MB → 128MB**。[`LIMIT_STEPS`] 仍为 128/256/512/1024/2048MB。`limitBytes` 用 `getLong(KEY, MAX_BYTES)`：**未写入过 prefs** 的新装/升级拿新默认；**已选过档位**的用户保留现值。UI「默认」徽标跟随 `MAX_BYTES`。 |
| **A11** | 预取 | `SettingsDefaults.ONLINE_CACHE_PREFETCH = false` + Prefs 双写；`PlaybackEngine` ticker 仅在打开时调用 `CachePrefetcher.plan`，关闭时 `cancel()`。候选本就只含 http(s)。 |
| **A11** | 并行分片 | `ONLINE_PARALLEL_DOWNLOAD = false`；`ParallelDownloadRegistry.obtain` 未开设置直接 `null`（走单连接缓存）。`SegmentPlanner.DEFAULT_SEGMENTS` **5→3**（开启后也偏省）。 |
| UI | 在线设置 | `SettingsOnlinePage` 播放缓存区增加两行 `SwitchRow`（可搜）；设置搜索 `ss_kw_*`。 |

## 边播边存（下载目录可自定义）

在「设置 → 在线播放 → 播放缓存」新增两项：**下载目录**（SAF 选目录并授予读写权限，可恢复默认清空）与**边播边存**（默认关，可恢复默认）。只对 http(s) 的在线歌曲生效，本地曲不写盘。

- 播放中：缓存已经补齐整首时，直接从缓存分片只读复制一份到目录，不联网、不占播放带宽。
- 切歌 / 单曲播完：这首不再出声后，用与预取相同的低限速把剩余分片补进**同一个** `SimpleCache`，再顺序拼接全部分片写入 SAF 目录；补齐失败只记日志。
- 文件名 = 歌名 + `Song.stableKey` 短哈希 + 后缀；同一首换直链不会重复落盘，同名不同歌不互相覆盖。目录里已有同名文件就跳过。
- **不影响后续播放**：不删缓存分片、不替换媒体项、不改队列、不触发曲库扫描；保存后的文件与当前播放源完全解耦。SAF 写失败 / 权限失效时静默退回，播放照旧。

实现见 `playback/OnlineSongSaver.kt`；触发点在 `PlaybackEngine` 的 ticker（3 秒节流）、`onMediaItemTransition` 与 `STATE_ENDED`。退出播放服务时先 `cancelAll()` 再释放 `SimpleCache`。

落盘成功后发一次 `DownloadsBus`，曲库域刷新虚拟列表 **「我的列表 → 边播边存」**（`DownloadedSongs`，只扫下载目录根层音频，按最近修改倒序；不写曲库、不触发扫描）。本地模式与洛雪模式的「我的列表」都有这一行；目录配置了即使 0 首也显示。文件名里的身份哈希在列表展示时剥掉。

## 歌词搜索（手动换词）

播放设置 → 当前歌曲 → **搜索歌词**；无歌词状态也直接给「搜索歌词」按钮。按歌名/歌手复用内置四家搜索找候选，点候选只拉取并展示**歌词预览**（列表标「已选」，不动当前歌词），确认后再按「使用这份歌词」才替换并写入 `LyricsOverrideStore`（按 `stableKey`）。之后同一首播放时手动版本优先于侧车 / 内嵌 / 自动在线取词；`LyricSource.MANUAL`（「手动选择」）会在来源 chip 上标出，可「恢复自动获取的歌词」清掉。实现：`data/online/LyricsSearch.kt`、`ui/LyricsSearchSheet.kt`、`data/LyricsOverrideStore.kt`。

## 性能

- 新装默认在线缓存封顶 128MB，少占 `cacheDir`。
- 默认无后台预取协程、无多连接分片探测/写盘；本地为主时几乎零额外成本。
- 需要在线加速时用户可自行打开；并行默认段数更低。

## 验证

- 单测：`OnlineMediaCacheTest`（默认 128 ∈ LIMIT_STEPS）、`SegmentPlannerTest`（3 段）、`SettingsDefaultsTest`（两开关与 Defaults 一致）、既有 `CachePrefetchPolicyTest`。
- 本机：`assembleDebug` + 上述相关测。
- 真机（可选）：纯本地队列无预取/并行网络；打开开关后弱网听在线曲。
