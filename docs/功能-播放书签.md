# 播放书签（H3）

> 落地日：2026-10-31（Asia/Shanghai）
> 版本：随 **v1.2.34** 发版

## 干了什么

为有声书 / 演唱会等**长曲**提供手动播放书签：

- 播放设置 →「播放书签」打开面板。
- **在此记书签**：把当前进度写入 Prefs（一首歌可挂多条）。
- 列表按位置升序；点「跳转」seek；可删除。
- 按 `Song.stableKey` 隔离。

## 为什么 Prefs

避免 Room schema 升级触发 destructive 清库。JSON 键 `bookmarks_json` 与 `music_player_prefs` 同文件。
