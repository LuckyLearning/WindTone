# 分享当前曲（N1）

> 落地日：2026-10-31（Asia/Shanghai）
> 版本：随 **v1.2.25** 发版

## 干了什么

播放页「播放设置」与曲库长按「歌曲操作」增加 **分享当前曲**：

- 调起系统分享面板（`ACTION_SEND`）。
- **永远**带文本：`标题` / `艺人 · 专辑` / `来自听风 WindTone`。
- **本地可读**时附带音频流（`EXTRA_STREAM` + 读权限 grant）。
- **云盘 / 在线 / http(s)**：只发文本，**不**下载、不导出远端文件。

## 为什么选「文本 + 本地音频」而不是「文本 + 封面」

| 方案 | 优点 | 缺点 |
|---|---|---|
| 文本 + 本地音频 | 微信/文件管理等可直接收到曲目；`content://` 无需拷贝 | 大文件部分接收方有上限；路径类需 FileProvider |
| 仅文本 + 封面 | 体积小 | 封面单独发出用处有限；仍要读缓存 |

选前者：更贴近「分享当前曲」的预期；云盘硬边界保证权限与合规（不强制把用户云文件导出给第三方）。

## 怎么干的

1. 纯逻辑 `ShareCurrentSong`：`textOf` / `isCloudOrRemote` / `canAttachAudio` / `plan` / `start`。
2. 云盘判定：`SongSource.REMOTE`、阿里云盘 `TrackFragment`（`ay=`）、`http`/`https` scheme。
3. 本地附带：`content://` 直接授出；`file://` / `Song.path` 经既有 `FileProvider`（authority=`${applicationId}.fileprovider`），`file_paths.xml` 增加 `external-path` 与 `cache-path name=share`。
4. 入口：`PlayerOptionsSheet`「当前歌曲」区；`SongActionsSheet` 长按菜单。
5. 单测 `ShareCurrentSongTest`。

## 怎么验

1. 播本地曲 → 播放设置 →「分享当前曲」→ 系统面板出现；选「复制」或备忘录应看到三行文本；可选微信等看是否带文件。
2. 曲库长按同曲 →「分享…」同上。
3. 播阿里云盘 / 在线 M3U 项 → 分享只有文本、无附件。
4. `./gradlew :app:testDebugUnitTest --tests com.luckylearning.windtone.ui.ShareCurrentSongTest`

## 不做什么

- 不把云盘文件下载到本地再分享。
- 不做应用内二维码 / 外链卡片。
- 不改通知栏 / 磁贴分享入口（需要时另开）。
