# 下一步规划（2026-10-26，基于 v1.2.3 代码现状）

> 定位：**只列还能做什么、值不值得做**，不含排期承诺。每项都标注了「依据」（代码/文档里的实证）与粗估工作量（人日）。

## 1. 现状盘点（实测，不是猜）

**已经比较完整的部分**

- 播放：变速 0.75–2.0x、变调 ±12 半音、均衡器 16 预设 + 混响、跳过静音、睡眠定时（3 模式 + 10 秒淡出）、断点续播、失败自动跳下一首。
- 曲库：五视图 + A–Z 索引、批量多选、歌单（拖动排序 / 去重 / 队列存歌单）、播放统计与 7/30 天报告、格式容量统计、在线歌单（m3u/pls/HLS）。
- 歌词：KRC/YRC/增强 LRC、双语合并（v1.2.1 修正）、偏移（长按行一次性校准）、悬浮窗预设化。
- 车机：左导航 + 右内容区、紧凑档自适应、播放页三段式控制、三大卡悬浮窗样式、按应用隐藏、无障碍掉线看护、开机后台起播。
- 工程：R8 混淆（含 mapping 归档与 retrace 脚本）、签名校验、869 项单测、发版四步验证链。

**明确缺的（按主题）**

| 域 | 缺口 | 依据 |
| --- | --- | --- |
| 播放 | 无 A-B 循环 | 全仓无 `abLoop` / `ABRepeat` |
| 播放 | 无交叉淡入、无音量均衡 | 无 `crossfade` / ReplayGain 相关代码 |
| 播放 | 无缝播放（gapless）未显式验证 | 依赖 Media3 默认行为，未做过整轨/现场专辑实测 |
| 车机 | 浏览只做一层下钻：无专辑 / 歌手 / 文件夹层级、无侧栏搜索 | 指南 §6.9 明确"刻意不做" |
| 车机 | 侧钮固定三颗，不能配顺序 / 数量 | `LyricOverlayService` 三钮写死顺序 |
| 歌词 | 新学：无「逐句循环」；旧：无在线搜词（产品否决） | 前者无实现，后者 `产品 l1` |
| 曲库 | 歌单只能导出、不能导入 m3u | `exportPlaylist` 有，`importPlaylist` 无 |
| 可观测 | 崩溃只落本机文件，靠用户手发；无聚合、无自动 retrace | `CrashLog` 只写文件 |
| 工程 | UI 级测试薄（仅 Settings/Car 若干）；CI 单轮 10–20 分钟 | `app/src/test` 目录分布 |
