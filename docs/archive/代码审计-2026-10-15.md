## 一、方法

**判据**：`引用数 = 全项目全词出现次数 − 声明次数`，`<= 0` 即候选。
private 成员按**文件内**统计（作用域即文件），internal / public 按**整包**统计。

| 手段 | 覆盖 | 关键坑 |
|---|---|---|
| 全词正则统计 | 零引用的 `fun` / `val` / `class` / `object` | **必须 `\b` 全词匹配**，否则 `Song` 命中 `SongIndex`、`seekBy` 命中 `seekRelative` |
| import 与正文比对 | 未使用的 import | `getValue` / `setValue` / `invoke` 等**委托与操作符约定**源码里不出现字面名，必须白名单排除 |
| UiState 字段 × UI 目录 | 「写了从没读」的状态 | 只搜 `.field` 形式，避免同名局部变量干扰 |
| 资源交叉引用 | `R.string` / `R.drawable` / `R.color` / `R.id` | 清单里引用的资源要算进去 |
| 依赖 import 比对 | 悬空的 gradle 依赖 | 传递依赖/扩展函数会误判，**须真机验证** |
| 注释块扫描 | 被注释掉的代码 | 含中文的按自然语言排除 |

**四类必然误报（看到别删）**：
1. **框架回调**：`onUpdate` / `onBind` / `onGetSession` / `onPlaybackStateChanged` / `onTaskRemoved` 等，由系统或 Media3 调用；
2. **父类调用**：`CoverRepository.sizeOf(...)` —— `LruCache` 算容量时回调；
3. **清单注册**：`PlaybackTileService`、`MusicWidgetProvider` 在 `AndroidManifest.xml` 注册，代码里搜不到引用；
4. **属性委托**：见上表第二行。
