# 功能 · 蓝牙自动车机（G7）

> 落地日：2026-10-31（Asia/Shanghai）
> 版本：随 **v1.2.35** 发版

## 干了什么

连接匹配的蓝牙音频设备时，**自动切入车载布局**（复用现有 `carMode` / `setCarMode`）；断开后可还原进档前的车载开关（可关）。

设置入口：**设置 → 外观 → 车载**：

| 项 | 默认 | 说明 |
|---|---|---|
| 蓝牙自动车机 | 关 | 总开关；关时不注册系统回调 |
| 断开后恢复先前布局 | 开 | 关则断开后仍保持车载布局 |
| 任意蓝牙音频 | 开 | 所有 A2DP/SCO/BLE 输出都触发；关掉则只匹配「记住的设备」 |
| 记住的设备 | 空 | 「添加当前已连接」写入 Prefs；可逐条移除 |

## 怎么干的

1. **纯决策** `BtAutoCarPolicy`：设备类型 / id / 匹配 / 进退出动作 / 名单编解码（普通 JVM 单测）。
2. **监听** `BtAutoCarMonitor`：仅在开关打开时 `AudioManager.registerAudioDeviceCallback`；进档快照 `carMode`，出档还原。
3. **Prefs**（不重建库）：`bt_auto_car_*` 键；会话态 `session` / `stash` 为运行时标记。
4. **权限**：声明 `BLUETOOTH`（≤30）与 `BLUETOOTH_CONNECT`（31+）。无权限时「任意蓝牙音频」仍可用（只看设备类型）；记住具体设备名/地址在 Android 12+ 通常需要授权，设置里诚实提示并可申请。
5. **UI** `BtAutoCarSettingsSection`；设置搜索目录补一条。
6. **单测** `BtAutoCarPolicyTest` + `SettingsDefaultsTest` 对质。

## 怎么验

1. 设置 → 外观 → 车载：打开「蓝牙自动车机」，保持「任意蓝牙音频」。
2. 连接车载/耳机蓝牙音频 → 应自动进入车载布局（大控件 / 直进播放页等既有行为）。
3. 断开蓝牙 → 应回到进档前的车载开关状态（若开了「断开后恢复」）。
4. 关掉「任意…」，点「添加当前已连接」后只对该设备触发；无权限时看提示。
5. `./gradlew :app:testDebugUnitTest --tests com.luckylearning.windtone.playback.BtAutoCarPolicyTest`

## 不做什么

- 不新建「场景」档位，也不强行套用 SceneMode「驾车」听感（场景芯片仍由用户手点）。
- 不在后台常驻扫描蓝牙；总开关关 = 零回调。
- 不做车辆品牌白名单启发式（交给「记住的设备」）。
