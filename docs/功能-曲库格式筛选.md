# 曲库格式筛选（H5）

顶栏调音图标打开底栏：可开「仅无损」，和/或按扩展名多选。两维取**交集**。状态写入 Prefs（`library_lossless_only` + `library_format_exts`），冷启动恢复。

## 口径

- 无损扩展名与格式统计页共用 `LOSSLESS_AUDIO_EXTS`（flac / wav / aiff / ape / dsf / dff / alac / wv / tta / tak 等）。
- **m4a / mp4 不算无损**（可能是 ALAC 也可能是 AAC，只看扩展名判不了）。
- 扩展名经 `normalizeAudioExtension`（含 WAVE→wav 等别名）。
- 列表：`visible = search(formatFilter(songs))`；分组浏览同样先过格式筛选。
- 「播放全部 / 随机播放」快捷方式尊重当前筛选；播放域曲库仍是全量（收藏、统计不受影响）。
- 车机导航无本筛选 UI（与手机顶栏一致入口若后续要加再开）。

## 实现要点

| 符号 | 作用 |
|---|---|
| `LibraryFormatFilter` | 数据类 + `isActive` / `NONE` |
| `applyLibraryFormatFilter` | 纯函数过滤 |
| `Prefs.libraryFormatFilter` | SP + DataStore 双写 |
| `LibraryFormatFilterSheet` | ModalBottomSheet + FilterChip |
| `LibraryHeader` | Tune 角标、活动 AssistChip、清除 |

单测：`LibraryFormatFilterTest`。
