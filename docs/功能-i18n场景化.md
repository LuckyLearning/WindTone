# i18n 场景化（第 8 批）

把场景化模式**芯片 / 播放设置「场景」入口**面向用户的文案收进既有 i18n 体系，并补齐读屏说明：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–7 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 8 批。

## 覆盖范围

- 分区标题 `scene_section`（播放设置抽屉「场景」）
- 芯片标签：`scene_drive` / `scene_commute` / `scene_sleep` / `scene_off`
- 分区提示 `scene_hint`
- 各档说明（读屏 contentDescription）：`scene_*_desc` + `scene_off_desc`
- 读屏组合模板 `scene_chip_a11y`
- 映射集中在 `SceneChipLabels`（与 `SceneProfiles.chipIds` 对齐）

说明：标签与 hint 在场景化功能落地时已进 strings；本批补 **desc 挂到芯片读屏**、抽出可测映射，并正式记为第 8 批。
