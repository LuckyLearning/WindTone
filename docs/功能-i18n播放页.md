# i18n 播放页（第 3 批）

## 范围

把 `PlayerScreen.kt` / `PlayerScreenParts.kt` 里面向用户的硬编码中文抽进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文
- 组合内 `stringResource` / `pluralStringResource`；非组合回调（Toast、导出默认文件名）用 `context.getString`

与第 1 / 2 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 3 批。

## 覆盖

- 顶栏 / 控制键 / 收藏 / 队列 / 播放设置等 `contentDescription`
- 「未在播放」、封面手势提示
- 状态行：歌词偏移 chip、睡眠倒计时、队列曲数（`player_queue_size` plurals）
- 车机侧钮无障碍 Toast 与侧钮描述
- 长按歌词：逐句循环菜单、校准偏移对话框
- 导出 LRC 默认文件名

## 不做

- `SheetsPlayback` / 设置页等其它模块硬编码（后续批次）
- 数据层 `artistOrUnknown` 等非播放页字面量

本功能**不重建数据库**。
