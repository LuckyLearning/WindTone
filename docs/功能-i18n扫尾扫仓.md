# i18n 可选残余（第 29 批）

承接第 28 批：抽取 **AliyunDrive 盘类型展示名**（备份盘 / 资源库 / 默认盘）。

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

详见 `docs/AI开发指南.md` § i18n 第 29 批。

## 覆盖范围

| 键 | 说明 |
| --- | --- |
| `aliyun_drive_backup` / `_resource` / `_default` | 云盘页账号头「当前盘」与切换胶囊展示名 |
| 数据层 | `AliyunRules.LABEL_*` 仍为中文**稳定键**（`availableDrives` / `backupRootParent` 匹配用）；**不改协议与下载路径** |

## 刻意保留 / 另批

- SoftEq / 播放内核（**禁止改**）
- **`LyricOverlayBridge` 长诊断文**（约 60 处；**另开批**）
- 内容库名、ProcStats 键、API raw message 等

## 性能（最高优先）

- **仅 UI 展示映射**：`aliyunDriveTypeLabel` + `stringResource`，账号头/胶囊重组时取串
- 不改列目录 / 取直链 / 播放热路径；**无常驻缓存**、无预加载整表
- 数据层 Pair 键不变，避免英文环境下 `backupRootParent` 匹配失败

- `AliyunDriveTest`（盘选择 / availableDrives）
