# i18n 可选残余（第 30 批）

**LyricOverlayBridge 长诊断 / 自检报告** 用户可见文案抽到 strings（本批一次收口外壳+结论+外观摘要）。

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

详见 `docs/AI开发指南.md` § i18n 第 30 批。

## 覆盖范围

| 前缀 / 对象 | 说明 |
| --- | --- |
| `lob_*` | `OverlaySnapshot.report()` ①–⑪ 行 + 结论；`snapshot()` 外观摘要 |
| `OverlayGeometryMarks` | 几何**协议**稳定子串（`未挂载` / `超出屏幕` / `异常` 等）；Service 写入、自检 `contains` 匹配 |

## 刻意保留 / 剩余

- SoftEq / 播放内核（**禁止改**）
- **Service `windowGeometry` 句面本身仍为中文协议串**（含坐标模板）；不做热路径 `getString`；报告第 ⑧ 行原样附带
- DiagLog「收起钮被点击」等日志句（非用户自检报告）
- 内容库名等其它可选 i18n

## 性能（最高优先）

- `report()` / `snapshot()` **仅设置页自检冷路径**；悬浮窗 tick / 播放回调**不**取 `lob_*`
- 几何更新仍写协议常量，**零资源查找**
- `AppStrings.s` + `ifEmpty`；无常驻大对象缓存

## 验证

- `./gradlew :app:compileDebugKotlin --offline`
- 相关：`OverlayPositionerTest`（几何夹紧既有单测，防回归）
