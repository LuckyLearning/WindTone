# i18n 可选残余（第 28 批）

承接第 27 批扫尾文档「可选」项：抽取 **OnlinePlaylistRules** 校验/友好错误句与 **BootStatusText** 开机诊断文案。

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

详见 `docs/AI开发指南.md` § i18n 第 28 批。

## 覆盖范围

| 前缀 | 模块 |
| --- | --- |
| `opr_*` | `OnlinePlaylistRules`：`normalizeUrl` 错误句 + `friendly` 网络异常（经 `UserFacingCopy.withNext`） |
| `bst_*` | `BootStatusText`：决策名 / 结果行 / 距今分档 |
| （已有 `shortcut_*`） | **AppShortcut** 桌面短/长标签：早已在 `shortcuts.xml` → strings，本批无 Kotlin 硬编码可抽 |

## 刻意保留 / 另批

- SoftEq / 播放内核（**禁止改**）
- ProcStats 键、API message、内容库名、UpdateChecker 分类子串、LyricOverlay 几何匹配键
- **`LyricOverlayBridge` 长诊断文**（约 60 处中文诊断句，体量大、偏排障；**另开批**）
- DiagLog 诊断句、测试夹具

## 性能（最高优先）

本批纯字符串抽取：

- **非播放热路径**：粘贴地址校验、设置页开机排障文案；不在 tick / 音频回调里调
- `AppStrings.s` + `.ifEmpty { 中文 }`：未 init 时零资源查找开销回落字面量；**不新建大对象缓存**、不预加载整表
- 展示时按需单次 `getString`，不在循环热路径重复取串

## 验证

- `./gradlew :app:compileDebugKotlin --offline`
- `OnlinePlaylistRulesTest` / `BootStatusTextTest`（纯单测，靠 `ifEmpty` 中文回落）

## 状态

**主路径 + Toast 扫尾 + 本批可选三项口径：OnlinePlaylistRules/BootStatus 已抽；AppShortcut 标签早已 strings；Bridge 长诊断另批。**
