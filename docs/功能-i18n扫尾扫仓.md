# i18n 全仓扫尾扫仓（第 26 批）

对 Kotlin/Compose 全仓再扫一轮用户可见硬编码，把**可安全抽取**的一截收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–25 批同一套约定。详见 `docs/AI开发指南.md` § i18n 第 26 批。

## 覆盖范围

| 前缀 | 模块 |
| --- | --- |
| `scope_*` / `drt_*` | `Prefs`：`ScanScope` / `DownloadRoute` 的 label/hint（枚举构造不再钉中文） |
| （复用 `sort_*` / `view_*` / `play_mode_*`） | `SortOrder.label`、`LibraryView.label`、`PlayMode.label` → `AppStrings` |
| `vp_*` | 虚拟歌单名 + 车机浏览树根标题 /「N 首」 |
| `qm_*` / `pls_*` / `sel_*` / `fav_*` / `bmk_*` | 队列 / 歌单 / 多选 / 收藏 / 书签 Toast 簇 |
| `ovn_*` / `ovp_*` / `ovs_*` | 悬浮歌词通知频道、水平位置文案、调整/预览提示行 |

## 刻意保留

- SoftEq 门控 / 滤波字面量 / 播放内核行为（**禁止改**）
- **ProcStats** 桶标签与 failReason 归类匹配键
- API 原始 `message`、日志、测试夹具
- 内容库名：`EqPresets` / `SoundSchemes` / `ReverbPresets`
- 机器可读协议键、BootTrace stage、scene id

## 残余清单（主路径近尾后）

Compose 主壳 / Sheet / 设置搜索等此前批次已抽；本批补上枚举旁路 + Toast 簇 + 悬浮通知。仍散落、可另开批：

- `LyricOverlayService` / `FolderController` / `M3uStore` / `UpdateRepository` 零散 Toast
- `OnlinePlaylistRules` 校验句、`BootStatus` 开机动作名、`AppShortcut` 短标签
- `AliyunDrive` 盘类型展示名、并行下载进度句（部分已 i18n 过半）
- 诊断包内仍作键用的中文（ProcStats 等，**有意不抽**）

## 验证

- `./gradlew :app:compileDebugKotlin --offline`
- `PlayModeTest` / `VirtualPlaylistInfoTest` / `LibraryBrowserTest` / `SortOrderPrefsTest` / `LibraryDrawerTest`

## 硬编码面

**主路径（用户日常可见 Compose + 枚举旁路 + 常用 Toast）已近尾。** 建议开发侧转产品项：**长稳资源回归**（规划 §7.3 #5，本机可做）；车上仍可并行勾 §5·E6。
