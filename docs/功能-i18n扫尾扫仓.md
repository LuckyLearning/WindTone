# i18n 扫尾（第 27 批）

承接第 26 批扫仓残余：把 **LyricOverlay / Folder / M3u / Update** 用户可见 Toast / 状态句 / 无障碍描述抽进既有 i18n 体系。

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–26 批同一套约定。详见 `docs/AI开发指南.md` § i18n 第 27 批。

## 覆盖范围

| 前缀 | 模块 |
| --- | --- |
| `fc_*` | `FolderController`：排除/取消排除、移除目录/分组、重匹配歌词、无音频权限 Toast |
| `m3u_*` | `M3uStore`：导出成功/失败、导入读失败/无匹配、信息更新、导入名回落 |
| `upd_*` | `UpdateRepository`：新版本/已最新、切换线路、安装失败与权限引导 |
| `uc_*` | `UpdateChecker`：非官方包、清单错误、DNS/超时/SSL/IO、下载失败描述 |
| `los_*` | `LyricOverlayService`：服务状态 report 句 + 收起/展开/打开播放页 contentDescription |

## 刻意保留（本批仍不抽）

- SoftEq 门控 / 滤波字面量 / **播放内核行为**（**禁止改**）
- **ProcStats** 桶标签与 failReason 归类匹配键
- API 原始 `message`、日志、测试夹具、DiagLog 诊断句
- 内容库名：`EqPresets` / `SoundSchemes` / `ReverbPresets`
- `UpdateChecker.DOWNLOAD_ABORTED_MSG` 与 IOException **分类匹配子串**（`安装包`/`大小不符`/`下载的安装包不完整`/…）
- `LyricOverlayService` **windowGeometry** 匹配键（`未挂载`/`异常`/`超出屏幕`/`文字View被隐藏` 等）
- `LyricOverlayBridge` 长诊断文、`OnlinePlaylistRules`、`BootStatus`、`AppShortcut`（可另开批）

## 残余（主路径 + 本批 Toast 扫尾后）

用户日常可见主路径与本批零散 Toast **已抽完**。仍可选、非阻塞：

- `OnlinePlaylistRules` 校验句、`BootStatus` 开机动作名、`AppShortcut` 短标签
- `AliyunDrive` 盘类型展示名（部分已 i18n）
- 诊断包内作键用的中文（ProcStats 等，**有意不抽**）
- SoftEq 文案收口（等 E6 结论后再动）
