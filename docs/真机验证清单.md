# 真机验证清单（v1.1.99）

> 基准：**v1.1.99**（versionCode **109**，发版 commit `3a40027`，清理 `07a224d`）。  
> 用途：只列**仍需真机**才能确认的项；模拟器已覆盖或产品已删除的内容不再出现。  
> 时区标注均为 **Asia/Shanghai**。
>
> **本批焦点（务必优先）**
>
> 1. **FR-07 车机悬浮窗样式大卡**（C1/C2/C3 + 字号步进 + 四角 chips；**无**驾驶中简化）
> 2. **阿里云盘侧车 / 本机同名歌词**（`LocalLyricsMatch`；不做网络搜词）
> 3. **无百度网盘**（入口、设置、云盘页均不应再出现百度）
>
> **DiLink 用户已确认（2026-10-26）**：**C-92 三颗侧钮（v1.2.0）已验证可以**。
>
> **DiLink 用户已确认（2026-10-25）**：原 P0-78～P0-91（前台识别 / 按应用隐藏 / 收起双钮 / 混淆签名关键八项 / 紧凑档）在比亚迪 DiLink 上「已验证可以」。下列「车机」分组对应项标 ☑；ROM 大改后再复测。
>
> 建议装 **Release** 包（`WindTone-v1.1.99-*.apk`），勿用 debug 测性能与存活。
