# 设计 · 快捷磁贴「收藏当前曲」（H1）

> 对应版本：v1.2.21（拟定）  
> 状态：已实现

## 背景

`PlaybackTileService` 注释长期写明：一个 TileService 只能有一个点击动作，装不下下一首和收藏——下一首已拆成 `NextTrackTileService`，收藏一直空缺。下拉快捷设置里想一键红心当前曲，是车机/锁屏旁路的高频动作。

## 决策

| 点 | 选择 | 理由 |
|---|---|---|
| 形态 | **独立第三颗磁贴** | Tile API 单热区；与播放/下一首并列，用户自选是否添加 |
| 落盘 | 复用 `FavoriteToggle`（本地 `song_state` / 阿里云 `AliyunTrackStore`） | 禁止磁贴另造收藏表；与播放页红心、批量收藏同一语义 |
| 无当前曲 | `STATE_UNAVAILABLE` + 副标题提示 | 点了没反应比假成功诚实 |
| 认不出身份 | 同上（在线直链未入库等） | 与对无 dbId 曲「点了不写」一致 |
| 已收藏视觉 | `STATE_ACTIVE` | 系统强调色约等于亮起的红心；标签固定「收藏」 |
| 应用内同步 | `FavoriteToggle.changes` → `LibraryViewModel` 改 `favoriteUris` 并刷虚拟歌单 | 磁贴在后台点了，回到 App 红心与「我的收藏」立刻对齐 |

## 数据流

```
FavoriteTileService.onClick
  → MediaController.currentMediaItem.mediaId（= Song.stableKey）
  → FavoriteToggle.toggleByMediaId
       ├─ aliyun:* → AliyunTrackStore.toggleFavorite
       └─ 其它 → songDao.idOf / SongIndex → songStateDao.setFavorite + index.bump
  → MessageBus（Snackbar，若界面在）
  → changes SharedFlow
       └─ LibraryViewModel 订阅 → favoriteUris ± key + refreshPlaylists()
```

## 非目标

- 不改随机播放模式、不热插拔、不做 crossfade。
- 不把收藏塞进播放/暂停磁贴的长按或多动作（系统不支持）。
