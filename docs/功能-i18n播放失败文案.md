# i18n 播放失败文案（第 21 批）

把 **PlaybackErrorMessages** 用户可见失败提示，以及 **UserFacingCopy**「原因 + 下一步」拼装模板，收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–20 批同一套约定。详见 `docs/AI开发指南.md` § i18n 第 21 批。

## 覆盖范围

### `pem_*`（PlaybackErrorMessages）

- HTTP 401/403/404/416/其它 4xx–5xx：原因 + 下一步
- DNS / 超时 / SSL / 本地缺失 / EOF
- Media3 `ERROR_CODE_IO_*` / 解析失败 / 未分类读取失败
- 并行分片超时 / 不完整 / 取消 / 不支持分段 / 失败（含内层原因）
- 本地缓存读取失败；兜底「复制诊断包」路径

非 Composable，走 `AppStrings.s`。

### `ufc_*`（UserFacingCopy）

- `ufc_next_mark` / `ufc_next_only` / `ufc_with_next`：中英各自标点与「下一步 / Next:」模板
- `hasNextMark` 同时认中英标记，兼容尚未抽完的硬编码路径（AliyunAuth / PlaybackEngine A-B 等）

## 刻意未改

- SoftEq / 播放内核行为 / Media3 配置
- `ParallelDownload` 抛出的 `IOException.message`（内部协议键；`PlaybackErrorMessages.ParallelMsg` 与之对齐，**不进 strings**）
- `looksLocalOrCache` / `isNetworkish` 里对协议键与英文系统异常词的匹配
- PlaybackEngine A-B / 逐句循环 / 悬浮锁定等其它 Toast（下一批候选）
- 设置搜索关键词表、排障报告正文
- versionName / tag / release
