# i18n 听歌报告与曲库统计（第 16 批）

把 **ListeningReportScreen** / **LibraryStatsScreen** 面向用户的硬编码中文收进既有 i18n 体系：

- `res/values/strings.xml` = 英文兜底
- `res/values-zh/strings.xml` = 中文

与第 1–15 批同一套约定，不另造框架。详见 `docs/AI开发指南.md` § i18n 第 16 批。

## 覆盖范围

### ListeningReportScreen（前缀 `lr_`）

- 标题复用 `lib_listening_report`；返回复用 `cd_back`；日历入口复用 `cal_title`
- 跨度芯片 `lr_span_days`；加载 `lr_loading`
- 分区：`lr_section_daily` / `lr_section_hours` / `lr_section_top_played` / `lr_section_top_listened`
- 概览：`lr_stat_total` / `lr_stat_avg_day` / `lr_stat_active_days`（天数值复用 `cal_active_days_value`）/ `lr_stat_peak_hour` + `lr_peak_hour_range`（空值 `cal_em_dash`）
- 空态：`lr_empty_plays` / `lr_empty_listen`；今日轴标 `lr_today_label`
- 榜单：`lr_play_count`；播榜 `lr_play_chart`

### LibraryStatsScreen（前缀 `ls_`）

- 标题 / 空态 `ls_title` / `ls_empty`；返回 `cd_back`
- 汇总：`ls_stat_*`；首数复用 `plurals/lib_song_count`；格式种数 `ls_format_kinds`
- 分区：`ls_section_by_size` / `ls_section_lossless_lossy`
- 无损/有损：`ls_lossless` / `ls_lossy` / `ls_unknown_format` + `ls_count_dot_size` + `ls_share_pct`
- 条形平均码率 `ls_avg_bitrate`；脚注 `ls_footnote_base` / `ls_footnote_unknown_size` / `ls_footnote_m4a`

## 刻意未改

- SoftEq / SoftEqSpike / 播放内核
- OnlineListeningReport（SettingsOnlinePage 在线报告；可下一批）
- SheetsScanScope / Aliyun 整包
- versionName / tag / release
- `formatListenDuration` / `formatByteSize` / `formatDayLabel` 数字格式化本身
